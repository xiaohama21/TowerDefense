# 烽火连营 · 三国塔防（TowerDefense）

三国题材章节制塔防：**塔就是三国武将**。每位武将拥有职业（骑兵、枪兵、弓箭手、术士、舞娘）、等级经验、转职路线与技能；剧情从黄巾之乱开始，一路守到五丈原。

![游戏截图](docs/screenshot.png)

- 完整流程：主菜单 → 游戏大厅（地图/养成/科技/设置）→ 编队 → 战斗 → 结算 → 解锁 → 存档
- 重复游玩：概率掉落表、信物装备、碎片升星、求贤抽奖（保底）、科技树、三档难度

- 完整流程：主菜单 → 游戏大厅（地图选择/武将养成/设置）→ 编队出征 → 战斗 → 结算 → 解锁下一关 → 存档
- 可玩关卡：第一章黄巾之乱**全八关**（涿郡 → 长社火攻 → 颖川 → 东郡 → 宛城 → 下曲阳 → 广宗前哨 → 广宗决战），每关配开场剧情
- 可收集武将：**9 名**（刘备/关羽/张飞/皇甫嵩/黄忠/貂蝉/周仓/赵云/诸葛亮），图鉴标注获取方式
- 怒气大招：满 100 自动释放（斩杀/横扫/齐射/鼓舞/轰击），特性八条 + 技能档位数值生效
- 武将养成：等级（上限 30）、一转（10 级 + 黄巾布×10）、重复通关得黄巾布
- 新敌人：黄巾力士（坦克）、祭酒（治疗光环）、渠帅张梁（Boss，召唤护卫自岔路进场）
- 地图主题：草原 / 长社火攻（暖色火光）/ 广宗夜战（调暗 + 火把）
- 局内成长：点击已建塔在地图正下方属性面板查看伤害/攻速/射程，可升级（伤害 +25%/级）与回收（返还 60% 投入）
- 数据驱动：关卡、波次、敌人、武将、转职、**战场布局（路径/建造位/装饰）**全部由 `.tres` 配置
- 通关结算：经验（最后一击 50% + 参与者均分）/ 首通解锁 / 掉落写入存档；失败不产生任何成长

## 玩法操作

1. 主菜单「开始游戏」→ 游戏大厅（左侧功能面板：地图选择/武将养成/设置）
2. 大厅「地图选择」先选章节再选关卡 → 编队选将出征；「武将养成」可升级/转职
3. 顶部建造栏选择武将，点击地图上的绿色 `+` 建造位部署武将塔
4. 点击「开始第 N 波」放怪；点击已建塔可在底部属性面板查看属性、升级或回收
5. 漏怪扣基地生命，守住全部波次即胜利并解锁下一关

## 运行与测试

- 引擎：Godot 4.7（GL Compatibility），分辨率 1280×720
- 运行：用 Godot 打开 `project.godot` 按 `F5`（从主菜单进入）
- 冒烟测试（战斗与数据）：`tests/SmokeRunner.tscn`
- 流程测试（解锁/编队/布局规范）：`tests/FlowRunner.tscn`
- 存档契约测试：`tests/Stage0Runner.tscn`
- 视觉预览：`tests/VisualPreviewRunner.tscn`
