# 烽火连营 · 三国塔防（TowerDefense）

三国题材章节制塔防：**塔就是三国武将**。每位武将拥有职业（骑兵、剑客、弓箭手、术士、舞娘、投石车）、等级经验、转职路线与技能；剧情从黄巾之乱开始，一路守到五丈原。

## 玩法操作

1. 主菜单「开始游戏」→ 游戏大厅（左侧功能面板：地图选择/武将养成/设置）
2. 大厅「地图选择」先选章节再选关卡 → 编队选将出征；「武将养成」可升级/转职/升星/信物/求贤；「科技树」消费科技点解锁全局加成
3. 顶部建造栏选择武将，点击地图上的绿色 `+` 建造位部署武将塔
4. 点击「开始第 N 波」放怪；点击已建塔可在底部属性面板查看属性、升级或回收
5. 漏怪扣基地生命，守住全部波次即胜利并解锁下一关

## 运行与测试

- 引擎：Godot 4.7（GL Compatibility），分辨率 1280×720
- 运行：用 Godot 打开 `project.godot` 按 `F5`（从主菜单进入）
- 冒烟测试（战斗与数据）：`tests/SmokeRunner.tscn`
- 流程测试（解锁/编队/布局规范）：`tests/FlowRunner.tscn`
- 存档契约测试：`tests/Stage0Runner.tscn`
- 视觉预览：`tests/VisualPreviewRunner.tscn`

## 目录结构

```

assets/       美术资源（v0.16.0：assets/decor 装饰 PNG，tools/generate_decor.gd 可复现）
```
