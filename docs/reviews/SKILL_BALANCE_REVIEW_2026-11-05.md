# 九将技能机制、数值与成长审查

审查日期：2026-11-05。基准：程序 **0.9.6.2**，Git `0e9ad04`，分支 `0.9.6`，GDD **v0.37.85**，CHARACTER_SKILLS **v0.18**。范围覆盖现有9名武将的27个技能及攻击成长、品阶、局内升阶、装备与天赋加成。孙尚香沿用 `huang_zhong`、典韦沿用 `zhou_wei` 兼容键。

**结论：人物机制和大部分基础倍率可以保留，但目前不能判定整套技能成长已平衡。优先处理两项零收益升级和强弱减速串联；随后校准积怒与持续增益，再调整个别技能的升级价值。现有技能增幅来源本身比较克制，主要缺口在触发频率、条件收益和升级成本。**

这是审查记录与调整建议，不是已采纳的设计变更。没有修改游戏配置、正式设计规格、版本号或玩家存档；没有提交、推送或合并分支。直连和127.0.0.1:7897代理拉取均失败，因此结论基于上述本地版本，未声称已核对远程最新状态。

## 1. 检查方法与结果边界

- 阅读当前三技能规格、重构提案、数值/天赋/装备文档，逐项核对角色资源、SkillRegistry、Tower、Enemy和Bullet实际结算。
- 执行现有 `SkillKitRunner`：**PASS，failures=0**；其中存档只读警告来自保存失败回滚用例。
- 执行现有 `BenchmarkRunner`：**PASS，failures=0，warnings=0**。它验证基线和品阶递进，不能据此证明跨武将平衡、每个技能升级收益或实战通关合理。
- 补充101组基础/升级/目标数/护甲/支援对照，2组典韦半血条件对照，42组合法装备与40点天赋组合对照；共**145组场景，每组60秒、3个固定种子，步长0.02秒**。使用真实Tower/Enemy/Bullet及既有基准驱动器，没有另造DPS伤害公式。
- 输出测试默认无科技、羁绊、信物、局内遗物和局内升阶；装备/天赋仅在42组专门场景开启。普通单体对照使用20护甲、高血量静止目标，目标不死，整窗生命高于50%。多目标默认10px紧密排列，全部在塔射程内。
- 支援对照为3座同配置关羽，加1座刘备或貂蝉，共享单个20甲木桩；统计全部来源的团队伤害，包括刘备自身输出。各组跟随塔与支援塔同步采用表内技能等级和局内阶数，必须与同一行对应的无支援基线比较。
- 静止不死木桩不会表达恐惧争取的行军时间、击杀返怒、爆燃链、换目标损失、隐匿反制和射程覆盖价值。**燕颔/爆燃在此场景零增益不等于技能无效；观星DPS不变不等于控制无效。**
- 首章设计目标是主力L20～30、绿阶核心能力；L100为跨章目标。L100仍打首章规格木桩只能用来审查成长和循环，不能直接当成首章通关难度结论。

## 2. 先处理的确定问题

### 2.1 青龙势和淬毒箭：花25本书，Lv1与Lv10完全相同

**青龙势**只配置 `hit_every=3`，实际必暴逻辑不读取技能等级；升级不增加暴击倍率，也不改变计数。**淬毒箭**的 `poison_dps=20` 被明确固定，持续3秒也不受技能等级影响；它没有其他可以成长的参数。两项都允许升级、正常扣书。

实测L40紫阶，单独升满：青龙势DPS **326.02→326.02**，淬毒箭 **132.58→132.58**；效果快照的等级增量也全部为0。不是界面漏显示，而是战斗没有等级收益。

建议优先补齐成长契约：青龙势保留每3次命中必暴，给必暴那一击设置可升级的额外伤害项；淬毒箭允许技能等级决定施加时的固定秒伤，例如先测试 **20→25.4/秒**，结算后仍绕过护甲、易伤及其他增伤。若坚持机制和全部数值固定，则应取消升级入口并返还已消耗的书。具体选择涉及设计变更，实施前须同步CHARACTER_SKILLS/NUMBERS/GDD，并登记BUGS。

代码依据：[必暴结算](../../scripts/Tower.gd#L1641)、[中毒施加](../../scripts/combat/SkillRegistry.gd#L126)、[固定值与升级规则](../../scripts/combat/SkillRegistry.gd#L336)、[升级扣书](../../scripts/data/PlayerProfile.gd#L736)。

### 2.2 诸葛亮的弱减速会长期保留张飞的强减速

Enemy当前分别保存“最强减速因子”和“最长剩余时长”，没有按来源保存各自到期时间。张飞60%减速2秒生效后，诸葛亮每0.25秒刷新8%减速，弱减速会不断续上整个状态的时间，已经保留的60%强度不会恢复为8%。

复现探针：先施加 `factor=0.4 / 2s`，随后约每0.24秒施加 `factor=0.92 / 0.5s`；10秒后实际因子仍为 **0.4**，期望应为 **0.92**。因此“张飞+诸葛亮”的长期控制贡献会超过两人的独立技能预算，先修这个问题再评估控制强弱。

建议按减速来源保存强度和到期时间，再从有效来源取最强值；同源刷新自身时间，弱源不能延长强源。对应文档和BUGS记录应在实际修复前先写入。

代码依据：[减速合并](../../scripts/Enemy.gd#L319)、[观星持续刷新](../../scripts/combat/SkillRegistry.gd#L154)、[当阳桥两段控制](../../scripts/combat/SkillRegistry.gd#L173)。

## 3. 共用数值与成长是否合理

### 3.1 通用3%线性增长本身温和，但不能代表所有技能的有效收益

设技能等级系数 `S=1+0.03×(等级−1)`，Lv10为1.27；技能增幅为 `a`，普通可成长技能值通常为 `基础×S×(1+a)`。大招额外加上独立大招增幅。技能升级不提高时长、范围、次数和阈值；时长通常受技能/大招增幅影响。

**普通伤害倍率和增益幅度的27%成长合理，可作为默认值。** 但当前存在三类例外，统一定价没有照顾它们：

1. **双项成长**：燕人咆哮、古之恶来同时提高触发率和追加倍率。期望追加伤害随S²增长，Lv10是Lv1的 **1.6129倍**，不是1.27倍；增幅不放大概率的限制已经正确落实。
2. **纯固定机制**：青龙势、淬毒箭没有可成长项，实际收益为0。
3. **很小的二级加成**：拜月5%→6.35%仅增加1.35个百分点；乘势每敌2%→2.54%、上限10%→12.7%，只是给已经存在的技能增幅再加一小部分，不能按“整招提高27%”理解。

升级成本1/1/2/2/3/3/4/4/5，升满25本；每一级增加的基础技能值仍是3%，后段每本书价值明显下降。这个递减结构可以保留，但必须先保证每个技能有真实且可感知的收益。首章全部首通只投放11本技能书，商店30元宝/本，25本的机会成本不低。

### 3.3 怒气把攻击成长再次转成大招频率，现有预算缺了这一层

输出武将共用 `命中4点+输入伤害×0.1` 的积怒口径。实际命中回调传入的是**打甲前、未裁掉溢出生命的命中伤害**；敌人护甲、易伤和有效扣血量没有反向参与这部分积怒。追加技能和普通大招不重复产生普攻积怒，这一事件边界已经正确。

因此攻击提高时，普攻变强，大招单发变强，积满怒气也更快。L1白阶→L100红阶、技能全部维持Lv1，关羽攻击只提高约 **4.78倍**，综合DPS提高 **14.02倍**，60秒大招5次→约23.3次。这个增长不能只用“技能倍率×1.27、技能增幅约×1.3”验收。

合法装备与40点天赋、无局内升阶的L100样本里，赵云可达 **57.3次大招/60秒**；30%攻速持续3秒的大招几乎变成常驻循环。它是怒气定位的一种优势，但常驻后再次增加时长的价值变小，也与“爆发窗口”定位产生偏差。关羽同场景28次、孙尚香31.3次、典韦26次、诸葛亮17次、皇甫嵩13次，频率差异足以改变技能预算。

建议在0.9.7校准中加入**每60秒大招次数、各增益覆盖率、有效扣血与积怒关系**，再决定伤害积怒部分是否封顶或归一化。可以先试“命中固定4点保留，伤害贡献设单次上限”的旋钮，并允许赵云怒气定位、关羽清杂返怒形成例外；具体上限应通过首章正常成长与后续章节目标一起确定，不直接把所有武将改成相同频率。

代码依据：[普攻积怒](../../scripts/Tower.gd#L781)、[近战命中回调](../../scripts/Tower.gd#L585)、[范围普攻每发积怒一次](../../scripts/Bullet.gd#L110)、[支援积怒](../../scripts/Tower.gd#L808)。

## 6. 建议实施顺序

> 用户已采纳本节建议并完成0.9.6.3实施；实际改动、前后对照与验收见[实施报告](SKILL_BALANCE_IMPLEMENTATION_2026-11-05.md)。本报告保留0.9.6.2审查时的判断及原始数据。

1. **先修确定问题**：两项零收益升级、弱减速续强减速；处理已消费技能书的补偿。实际修复时登记BUGS、复现和根因，先同步设计结论及版本关联。
2. **补齐共用预算**：逐将记录普攻、大招、概率追加、状态、击杀链和团队贡献；单发倍率之外加入频率、覆盖率、控制时间、目标数和金币效率。先用真实合法成长档L20/绿、L40/紫、L100/红测，不能只用L100打首章。
3. **优先改善低价值升级**：温酒、拜月、乘势、燕颔、纯穿甲类技能；可以选择不同成长斜率或不同升级成本。固定统一25本的前提应是收益大致处于可接受区间，不能用“都是+27%”代替评估。
4. **再收敛数值**：先校准伤害积怒/大招长期覆盖，保留典韦4+4斩杀、关羽三拍真伤、孙尚香基础反隐、张飞两段控制及两位辅助的覆盖身份。若赵云清杂与群体定位仍过度重叠，再单独动目标数或递减；不一次改多项旋钮。
5. **最终验收补场景**：首章8关正常成长通关/时长/剩余金币；短命杂兵与甲光环精英；满血/半血Boss；同角色多塔；张飞+诸葛亮控场；皇甫嵩预挂灼烧死亡链；刘备/貂蝉覆盖1/3/6友军；多路径分散敌人及隐匿反制。现有回归通过继续保留，但这些场景完成之前不将本报告的测试候选值写成已定稿平衡结论。
