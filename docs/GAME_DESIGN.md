## 1. 游戏概述

- **类型**：单机章节制塔防（普通关 10~15 分钟、Boss 关 20~30 分钟，v0.7 统一口径），带局外养成（Roguelite-lite）。
- **核心概念**：玩家防守的"塔"就是具体三国人物（如关羽、黄忠）。每个武将属于一个职业（骑兵、弓箭手、术士、舞娘等），拥有独立的等级、经验、转职路线与技能。
- **一句话玩法**：选择关卡 → 编队出征 → 在战场上建造武将塔 → 击杀敌军波次 → 守住基地 → 通关结算（经验、掉落、角色解锁）→ 养成武将 → 挑战更强关卡。
- **双循环**：
  - 局内循环（每局 10~30 分钟）：经济（杀怪金币）→ 建造/升级武将 → 防御波次 → 胜利或失败。
  - 局外循环（长期）：经验 → 等级 → 转职 → 更强的武将 → 解锁新关卡/新角色 → 掉落 → 抽奖。

## 2. 核心玩法循环（详细）

```
主菜单
  └─ 章节选择（第一章：黄巾之乱）
	   └─ 关卡选择（按顺序解锁，可重刷已通关关卡）
			└─ 编队（从已拥有武将中选出 squad_size 个出战）
				 └─ 战斗
					  ├─ 波次准备期：查看敌人预告，规划建造
					  ├─ 波次进行中：建造武将塔、击杀获得金币与经验
					  ├─ 失败：基地生命归零 → 结算失败 → **局内经验/掉落全部作废**
					  └─ 胜利：清空全部波次 → 结算
						   ├─ 参战武将获得经验（含击杀经验与通关参与经验）
						   ├─ 获得首通/重复通关掉落
						   ├─ 解锁新武将（首通奖励）
						   └─ 解锁下一关（按 prerequisite_stage_ids）
				 └─ 养成界面（武将详情）
					  ├─ 升级（消耗经验自动结算）
					  ├─ 转职（满足等级 + 消耗材料）
					  └─ 抽奖【阶段4】求贤令 → 新武将 / 碎片
```

**核心规则（不可违背）**：局内获得的所有经验、掉落、解锁均先进入"会话暂存"（`BattleSession` 的 pending 数据），**只有通关胜利后才提交写入存档**；失败、中途退出、放弃一律作废。该规则已由现有 `BattleSession` + `PlayerProfile.apply_battle_session()` 实现，后续不得绕过。

- **提交 1（待排期）——可选挑战目标**：每关结算附加 3 个全局目标（不使用军需通关 / 基地生命 ≥80% 通关 / 击败全部精英，自动判定，见 STAGES.md 5.8）；每达成 1 个奖励少量材料（草案：黄巾布 ×2，见 NUMBERS.md 10.11）；达成数 = 关卡星级（0~3 星）写入存档，重复通关取历史最优；挑战目标不设主线门槛、不锁定任何内容。
- **提交 2（待排期）——系统渐进解锁与首用说明**：按关卡通关进度解锁系统入口（节奏：1~2 关建造/开波/基础职业；3~4 关大招/技能/敌人机制；5 关升阶/回收/军需；6~7 关遗物/羁绊/科技；8 关 Boss 综合）；已拥有/已通关内容不限制使用；首次使用弹一次简短说明（可跳过、不重复弹）。

## 12. 防跑偏铁律（Do / Don't）

- ✅ 内容一律走 `.tres` 配置；❌ 禁止在脚本里硬编码角色/敌人/关卡数值。
- ✅ 经验/掉落/解锁必须通关后才提交；❌ 禁止任何"失败也保留成长"的旁路。
- ✅ 每个阶段结束可完整游玩；❌ 禁止开发未排期的【远期】内容（多分支转职、二转、抽奖 UI、后续章节）。
- ✅ 抽奖只加速、不卡主线；❌ 禁止让抽奖成为获取关键流程角色的唯一途径。
- ✅ 挑战目标只作结算附加项；❌ 禁止因未达成挑战目标而锁定内容或卡主线进度。
- ✅ 新增敌人/角色先建数据再写行为；❌ 禁止为单角色硬编码攻击逻辑。
- ✅ 修改数值/玩法设计必须先更新对应设计文档（总纲或模块文档）；❌ 禁止文档与实现分叉后继续开发。
- ✅ 转职不可逆，`promotion_path` 记录历史；❌ 禁止转职回退或重复转职。
- ✅ 大招与特性通过配置字段 + 行为 ID（`ultimate_id` / `trait_id`）驱动；❌ 禁止在塔脚本中硬编码某角色的专属逻辑（行为注册表见 modules/BEHAVIORS.md）。
- ✅ 怒气与局内升级等级为临时状态；❌ 禁止怒气/大招/局内升级等级写入存档。
- ✅ 保持单机、本地存档；❌ 禁止在 2026 年前规划联机/云存档/内购（【远期】另行立项）。
