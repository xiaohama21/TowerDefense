## 0. 范围与硬约束

**范围**：主城（替换现大厅功能面板）/ 酒馆（武将获取改版）/ 坐骑（并入装备系统）/ 兽栏与战宠 / 驯兽师（第 7 职业）/ 军需删除与局内金币口径（升阶强化）。

**硬约束**：
1. 单机、本地存档、无系统时钟（无每日 / 每周刷新类设计）。
2. 失败 / 退出不带出任何成长（元宝 / 招贤榜 / 将魂同口径）。
3. 数值走总闸门预算（武将重构稿 §5.4）；战力轴不新增并行乘区。
4. 图徽优先（AGENTS §6）：元宝 / 招贤榜 / 将魂 / 建筑 / 战宠等新概念缺图徽 → 虚线圆占位 + `ART_PROMPTS.md` 登记。
5. 先文档后代码：本稿拍板并完成模块回写后，方可进入开发；分支按 AGENTS §5。

## 2. 现状核对（2026-10-14）

- 流程：主菜单 → 游戏大厅 `GameHub`（左功能面板：地图 / 武将养成 / 科技树 / 军需处 / 背包 / 设置 / 百科）→ 选关 → 编队 → 战斗。
- 武将获取（CHARACTERS 4.3）：**首通解锁为唯一来源**——初始刘备 · 关羽；s02 张飞 / s03 黄忠 · 皇甫嵩 / s04 貂蝉 / s05 周仓 / s06 赵云 / s07 诸葛亮；求贤（GachaService）自 v0.30.0 暂停保留。
- 升阶（NUMBERS 10.9）：0~3 阶；费用 `build_cost × 0.8 × n`；职业差异化步进、等效约 +30%/阶（满升 ≈ ×1.95）；大招随阶 `1 + 0.25 × rank`。
- 军需（0.8.16 / 0.8.17 刚落地）：6 件 / 默认 2 槽（科技 +1 → 3）/ 购买 → 军需带 → 择时使用；军功唯一用途 = 军需解锁 / 强化；局内底栏军需 3 槽（0.8.17.0 HUD v2 组成）。
- 元宝（阶段 9 新增、未实装）：草案首通 +30 / 重复 +10（困难 ×2）；价格草案：制式装备 120 / 技能升级书 30 / 材料 8~40 / 商店刷新 10~30。
- 阶段 9（0.9.1~0.9.7 武将重构：装备 / 天赋 / 技能升级 / 元宝 + 双商店 / 主公等级）已排期、未开工。

## 3. 主城

### 3.1 定位与流程

- 「开始游戏」→ 直接进主城全屏场景，**替换现 GameHub 功能面板**；出征 = 城门 → 选关 → 编队 → 战斗；战斗结束回主城。
- 主城 = 容器 + 渐进解锁载体 + 阶段 9 经济轴（主公等级 / 双商店）的具象化；**不自带独立养成 / 数值系统**。
- 系统功能（设置 / 返回主菜单 / 退出）留右上齿轮菜单，不做建筑；编队保持在出征流程内。

### 3.2 建筑表（9 座）

| 演武场 | 武将养成：等级 / 品阶 / 技能 / 天赋 / 装备（含坐骑槽） | 阶段 9 各系统统一入口 |

- 命名：主城可称「**大营 / 连营**」（呼应标题），建筑走军营风；最终命名随概念稿定。

### 3.3 状态与解锁

- 不做自由摆放（远期「装修层」另议）。

## 4. 酒馆（武将招募）

### 4.1 口径

- 池 = **全部已实装武将**（新武将随版本直接入池，无章节门槛）；初始武将（刘备 / 关羽）不变，其余全部走酒馆获取。
- **3 个候选位、3 选 1**；**固定 50 元宝 / 名**；已拥有可重复招募 → 转该武将「将魂」（1 名 = 1 枚，见 §4.3）。
- 流程：支付 50 → 招募 1 名 → 本轮结束**自动补新批**；不满意可花「招贤榜」手动换一批。
- 栏位双门槛（已定）：栏位 2 = 通关 `ch01_s01` + 主公 L3；栏位 3 = 通关 `ch01_s03` + 主公 L6。
- 新档初始元宝 = **100**（开局可招 2 名）；`ch01_s01` 结算后引导「去酒馆招募」。

### 4.2 首通奖励改版

- 取消「首通解锁武将」：首通奖励改发 **元宝 + 招贤榜 ×1**（+ 阶段 9 已规划的装备 / 材料条目照旧）。
- STAGES 关表「首通解锁 / 奖励」列整体重排；`unlock_stage_id` 废弃（字段保留兼容，不再作硬门槛）；图鉴未拥有文案改「酒馆招募」；「解锁硬规则」条删除。
- 解锁链路相关测试（UnlockRepro / FlowRunner 用例）重写。
- 与铁律关系：武将获取 = 确定性货币购买（非抽奖），主线不依赖随机；「抽奖只加速、不卡主线」条维持。

### 4.3 招贤榜 / 将魂 / 旧求贤

- 招贤榜（新道具）：刷新酒馆全部 3 栏；来源 = 首通 ×1、重复通关 30%、市集上架、结算转盘（**替换原求贤令位**）。
- 将魂：每武将独立计数（`characters[id].soul`）；**重复招募转化 1:1（每重复 1 名 = 1 枚该武将将魂）**；用途 = 后续「武将超越」（另行设计，本期只落数据 + 图鉴展示）。
- 求贤令（`gacha_token`）与 `GachaService` 正式废弃，随 schema 迁移清理。

### 4.4 元宝锚点（已定：维持阶段 9 投放草案）

- 锚点：**50 元宝 = 1 名武将**；元宝投放**维持阶段 9 §9.1 草案**——首通 +30 / 重复 +10（困难 ×2），不重锚。
- 节奏自洽：第一章首通 240 + 新档初始 100 ≈ 340 ≈ 6.8 次招募（全将 7 × 50 = 350），第一章内基本可招齐（少量重复 / 转盘补齐）；装备 120 / 技能书 30 等价格草案维持。
- 价值序提示：武将 50 低于制式装备 120——装备定位仍为后期奢侈项，随 0.9.7 / 10.2 实测复核。

## 5. 坐骑（并入装备系统）

- 每武将 **1 个坐骑槽**（与武器槽并列的装备大类）；复用品质 / 词条 / 掉落 / 商店链路（重构稿 §8）。
- 入口在演武场 → 武将 → 装备页；**不做马厩建筑**。
- 首版 = 装备件（获取即用、可替换）；远期可选「半养成件」（独立等级 / 成长），不在本期。

## 6. 兽栏 · 战宠 · 驯兽师

### 6.1 两步走

- **第一步（兽栏）**：收集 / 孵化 / 养成 / 出战配置；不含局内单位。
- **第二步**：战宠出战单位实装 + 驯兽师职业。

### 6.2 局内形态（第二步口径）

- 战宠 = 队伍携带的**常驻友方单位（默认 1 只）**，开局自动部署；**默认 AI 自动索敌**，点击可接管手动（移动 / 指定目标），再点交还 AI。
- 技能与被动**自动释放**（减操作压力为红线）；阵亡进冷却，本局由驯兽师复活。
- 不占建造位、不吃建造金币（金币口径见 §7）。
- 待定：战宠与局内其他系统（升阶 / 大招节奏等）的交互——按「独立单位、独立面板」原则，随 10.5 设计稿定。

### 6.3 深养成骨架（第一步细化，细则随 10.4）

- 属性层：等级（出战经验）/ 资质（孵化随机掷：攻击 / 生命 / 攻速 / 技能倍率）/ 品阶。
- 技能层：主动 1~2 + 被动 2~4；技能书迁移（打书）——细则待设计稿。
- 突破层：进化 / 突破（材料来自重复战宠融合）。
- 获取：关卡掉「兽卵 / 幼崽」→ 兽栏孵化 → 资质随机；重复战宠 = 融合材料。

### 6.4 驯兽师（第 7 职业）

- 定位：战宠流；普攻偏弱 + 战宠联动补偿，总强度对齐总闸门（与现 6 职业同一预算表）。
- 技能框架（建议）：①召唤 / 召回（瞬移战宠至指定点并强化）；②战宠光环（攻速 / 伤害）；③大招兽群 / 合体。
- 依赖：`BehaviorRegistry` 新行为模板、职业数据（`resources/professions/`）、科技树「军略」新增职业分支（≤10%）、百科 / 图鉴、SKILLS / CHARACTER_SKILLS / PROFESSIONS 回写。

### 6.5 兽栏栏位

- 默认 **1**；扩展位按双门槛（示例：2 号位 = 主公 L15 + 通关第二章指定关；3 号位 = 主公 L25 + 通关第二章）——待第二步设计稿定值。

## 7. 军需删除 + 局内金币

### 7.1 删除清单（随主城版本）

- 建筑 / 入口：军需处（`SupplyDepotPanel.gd`）与大厅入口。
- 局内：底栏军需 3 槽（0.8.17.0 HUD v2 组成）、军需面板（`ui_supply`）、`BattleSupplyData` 6 件、购买 / 使用链路、军需相关提示与浮字。
- 科技：「军府调度」（军需带 +1）条目删除，军略 / 将略页签同步清理。
- 数值 / 文档：NUMBERS 10.15、UI_LAYOUT §10 / §16、UI.md 军需行、STAGES 奖励口径军需条目、`ui_supply.png` / `ui_supply_depot.png` 归档注记。
- 测试：军需相关用例删除（FlowRunner / SmokeRunner / Stage0Runner 断言）。
- 军功：掉落保留；用途由阶段 9「军功商店」接盘（删除时点 = 阶段 10，双商店已存在，无空窗）。
- 工作量提示：0.8.16 / 0.8.17 军需相关实现作废（2026-10-14 已确认接受）。
- 底栏改版：军需 3 槽移除后的底栏布局（建造位 / 塔详情取宽或留白）随 10.3 UI 稿定。

### 7.2 局内金币口径

- 消费只保留 **建造 + 升阶**；不新增任何机制；结算转盘（剩余金币 ≥150 抽 1 次）维持现状。
- **升阶强化**（2026-10-14 拍板）：
  - 加成：职业步进整体上调（等效 +30%/阶 → **+40%/阶**，满升上限 ≈ ×1.95 → **≈ ×2.6~2.8**）；**大招随阶保持 `1 + 0.25r` 不变**（2026-10-14：暂不加强）。
  - 费用（已定）：`build_cost × 0.8 × n` → **`build_cost × 1.2 × n`**（第 1/2/3 次 = 1.2 / 2.4 / 3.6 倍造价；总投资 4.8 → 7.2 倍，+50%）。
  - 边界不变：费用向上取整；结算期禁止消费；拆塔清局内状态。
  - 风险：关位标定（STAGES 锚点按「升阶 2」推算）需全章基准回归复核；科技「升阶折扣」价值同步上升；难度 / 波次预算复核。
