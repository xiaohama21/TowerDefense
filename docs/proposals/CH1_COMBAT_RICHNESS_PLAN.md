## 3. 隐匿机制与破隐来源

### 3.1 机制定义（采纳）

- **隐匿是状态**：不可被选中——不参与普攻/单体/需选目标技能与大招索敌；无目标框、不显示血条（保留行进警示）。
- **命中口径（采纳）**：
  - 以单位为目标的攻击（普攻/单体/需选目标技能/自动大招）隐匿期打不到，需破隐。
  - **范围/无差别区域效果可命中隐匿**（军需火攻、焚营类区域、区域大招）——范围克隐匿，破隐负责精确锁定/高效单点。
- 隐匿与护甲独立两轴，可叠加（s07 隐方士、张角 P3 亲卫）。

### 3.2 破隐来源（采纳：军需暂不增加破隐）

| 来源 | 载体 | 说明 |
|---|---|---|
| 固有破隐 | 黄忠（弓箭手·哨戒） | 对隐匿自动可见（s03 解锁 → s06 首隐前必有） |
| 全图点亮 | 诸葛亮·借东风（观星） | 借东风期间全图破隐（s07 解锁） |
| 范围光环 | 舞娘（貂蝉）局内升到 3 阶后 | 作用范围内友军获得破隐（半径 = 光环/射程，视觉波纹提示） |
| 转职/科技【远期】 | 弓箭手二转"哨戒线"；科技"瞭望" | 常驻破隐 |

- **军需不加破隐**（火攻/烽火点亮不引入）。
- s06 首隐反制链条：黄忠（固有，可靠）为主；无黄忠阵容以"范围盲压 + 漏怪预警"兜底（范围可命中隐匿已采纳）；借东风（s07）/舞娘 3 阶为后续强化。
- 破隐刷新规则（待确认）：点亮期间可锁，离开覆盖/效果结束即恢复隐匿（不做一次性现形）。

### 3.3 教学与预警

- s06 观察波：1~2 只慢速高漏隐刺客，虚影 + 音效预警，漏怪时提示引导补破隐。
- 隐匿单位进入破隐覆盖或被范围命中时播"现形"演出。

### 3.4 数据/实现补丁点

- `EnemyData`：隐匿状态（`&"stealth"` 或 `stealth: bool`，登记 BEHAVIORS B.3.2）。
- `Tower` 目标选取：索敌按"塔是否破隐 + 敌是否隐匿"过滤。
- 范围命中：区分"绑定单位"（需可见）与"无差别区域"（可命中隐匿）。
- 舞娘 3 阶光环按帧刷新范围内友军破隐。
- `SkillRegistry`：破隐作"可授予 flag"聚合（固有/光环/全图/转职/科技）。

## 4. 护甲模型（v0.4）与伤害类型

### 4.1 现状问题

v0.7 线性减算 `max(伤害−护甲, ceil(伤害×10%))`：1 甲 = 1 伤害 = 1 穿透，随玩家单发成长线性失效，对物/魔无差别。需重设计。

### 4.2 伤害类型（采纳 + v0.4 真伤单体技能化）

| 类型 | 对护甲 | 可否被减伤 | 代表来源 |
|---|---|---|---|
| 物理 | 算全部护甲 | 被护甲减免 | 近战/箭/投石普攻、大部分技能/大招 |
| 魔法 | 算 50% 护甲 | 被护甲减免（半额） | 术士类、火攻/灼烧 DoT、术法区域 |
| 真实 | 无视护甲 | 不可被任何减伤 | 处决/斩击类 + **部分单体技能改真伤** |

**单体技能真伤化（v0.4 草案，待确认清单）**——把重甲的"单点解"给到单体爆发角色，同时该技能不再吃护甲：

| 技能 | 原 | 改为 | 备注 |
|---|---|---|---|
| 关羽·青龙偃月 | 2.5× 物理单体 | **真实伤害单体** | 保留击杀返 CD；成"重甲单点斩" |
| 骑兵大招 `ultimate_cavalry_breaker` | 3× 单体·斩杀返怒 | **真实伤害单体** | 斩击/处决语义契合 |
| 黄忠·定军山 | 2.5× 物理单体 + 易伤 | 保持物理 | 其定位是"易伤标记铺普攻"，不强行真伤 |

> **所有伤害描述必须标注伤害类型**（物理/魔法/真实）：技能说明、图鉴、飘字/演出、军需与遗物文案一并改写；改型会同步更新 `CHARACTER_SKILLS.md` / `SKILLS.md` / `BEHAVIORS.md` 对应行。
> 真实来源仍克制（仅处决/斩击 + 上表），防真伤把护甲与类型一起架空。

### 4.3 护甲结算公式（采纳：C=50、无保底、单源 ≤30%、同源取最高、跨源乘算）

```text
1) 类型系数：armor_eff = max(armor × f_type, 0)
     f_type：物理 1.0 / 魔法 0.5 / 真实 0

2) 百分比穿甲（跨不同来源乘算；同源不叠加取最高）：
     对每个"不同来源"，取其一最强值 pᵢ；同武将塔/同技能多座塔不叠加，取最高。
     单来源上限 ≤30%。
     剩余系数 = Π(1 − pᵢ)（对不同的来源）
     armor_p = armor_eff × 剩余系数

3) 固定穿透：armor_f = max(armor_p − pen_flat, 0)

4) 减伤：m = armor_f / (armor_f + 50)
     实际伤害 = 基础伤害 × (1 − m)
     真实伤害：跳过 1–4，恒 = 基础伤害
```

- **不设保底**：减伤为 `armor_f/(armor_f+50)` 的比值型，随甲值渐近 <100%，永不归零，故无需保底（真实除外本就满伤）。
- 多来源百分比穿甲**乘算**；单来源 ≤30%；同来源多塔取最高不连乘，防重复造塔堆穿甲。

### 4.4 算例（C=50）

| 情形 | 计算 | 实际伤害占比 |
|---|---|---|
| 无甲 | 0 → 0% | 100% |
| 物理 vs 甲10 | 10/60 = 16.7% | 83% |
| 魔法 vs 甲10（5） | 5/55 = 9.1% | 91% |
| 物理 vs 甲20 | 20/70 = 28.6% | 71% |
| 魔法 vs 甲20（10） | 10/60 = 16.7% | 83% |
| 物理 vs 甲30 | 30/80 = 37.5% | 62.5% |
| 物理 vs 甲30 + 两种穿甲 20%+25%（乘 0.6） | 18/68 = 26.5% | 73.5% |
| 物理 vs 甲30 + 同源两塔各 20%穿甲（取最高 20% 不乘） | 24/74 = 32.4% | 67.6% |
| 真实 vs 任何 | 跳过全部 | 100% |

## 7. 数值测算与校准（锚点）

- 单波清怪 40~80s：波血池上限 ≈ `塔DPS × 目标秒 × 命中(0.7~0.85) × (1−减伤期望)`。
- Boss 阶段 HP ≈ `Σ(塔DPS × 阶段输出秒 × 命中 × (1−减伤期望))` + 30~40% 召唤/走位损耗。
- 减伤期望按 §4.3（魔法半甲、跨源穿甲乘算、C=50）算；张角 HP 分 2~3 输出窗。
- 全部新增怪/Boss/护甲/破隐数值先进 `tests/BenchmarkRunner.gd` 回归再定稿。
