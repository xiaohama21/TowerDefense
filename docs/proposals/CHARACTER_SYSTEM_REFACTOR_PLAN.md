### 0.1 属性词典（v0.3 新增，全稿与后续模块文档统一口径）

| 术语 | 定义 | 典型来源 | 写法示例 |
|---|---|---|---|
| **攻击力** | 武将面板主属性，按普攻类型分**物理攻击**（物理系武将）与**魔法攻击**（法系武将）；数值语义 = 现 `base_damage`（基础攻击），随等级 / 品阶成长并叠加装备固定加值 | 基础值、等级、品阶、装备固定值、天赋 | 「物理攻击 +5」「魔法攻击 +6」 |
| **伤害** | 单次命中的结算输出 = 攻击力 × 普攻 / 技能倍率 × 各乘区；**必须带类型**（物理 / 魔法 / 真实）或写「所有伤害」 | — | 「物理伤害 +8%」「所有伤害 +5%」 |
| **攻击速度** | 攻击间隔的倒数语义（interval ÷ 倍率），只影响普攻频率 | 等级、品阶、装备、天赋 | 「攻击速度 +8%」 |
| **暴击** | 普攻专属判定，见 §5.5；分暴击率与暴击伤害两条 | 品阶、装备、天赋 | 「暴击率 +4%」「暴击伤害 +15%」 |
| **技能增幅** | 非普攻类技能的数值乘区，见 §5.6 | 品阶、装备、天赋 | 「技能增幅 +6%」 |
| **技能值** | 非普攻技能的全部数值：伤害倍率、友方增益（幅度 / 时长）、敌方状态（强度 / 时长）——统一由**技能增幅**乘区计算（§0.3 A 组） | — | 「技能增幅 +6%」 |
| **装备特效** | 装备专属的**命名固定效果**（如「斩将」对精英 / Boss +25%）；同名不叠加（§0.3 C 组） | 装备 / 信物 | 「斩将：对精英 / Boss 伤害 +25%」 |

- **攻击力 ≠ 伤害**：攻击力是面板属性（进成长与乘区链），伤害是结算输出；「物理攻击 +5」与「物理伤害 +5%」是两种不同词条，禁止混写。
- 装备固定攻击加值计入**基础攻击**（与 `base_damage` 同点位、同乘区），随等级 / 品阶成长同倍放大；凡品单件 ≈ 该职业基础攻击的 +7~11%（档位见 §8.4 / §8.5）。
- 真实伤害**不可被减免，但可被增伤与暴击**（增伤不是减免）。
- 状态伤害（灼烧 / 冰冻 / 雷电等）为**技能面板固定值**：不可增加、不可削减（不吃增伤 / 减伤 / 暴击）——v0.3 用户口径。
- 攻击类型沿用 `ProfessionData.attack_damage_type`（现况：术士 = 魔法，其余职业 = 物理）；法系武将的技能同样以魔法攻击为基准。

### 0.2 词条书写规范（v0.3 新增，红线）

1. **禁止裸写「伤害 +8%」**——必须写明类型（物理 / 魔法 / 真实）、范围（所有伤害）或改为面板属性（物理攻击 / 魔法攻击）；条件增伤（对精英 / Boss、对灼烧目标等）只允许出现在技能 / 天赋 / 特效参数中（带名称与固定值；特效暂不实装，§0.3 C 组）。
2. 每条词条必须可由程序直接读取（`stat_key + 数值 + 类型`），禁止"攻击提升""更强"这类模糊文案；UI 一律按图徽口径表达（AGENTS §6）。
3. 数值描述精确到单位与语义：`+N` = 固定值（攻击 / 怒气 / 等级），`+N%` = 百分比；「攻击速度 +8%」= interval ÷1.08，不允许写成"攻速变快"。
4. 存量文档 / 卡片 / 概念稿按本规范批量改写（清单见 §15.3）：旧「术法伤害 +12%」→「魔法伤害 +12%」；旧「伤害 +8%（职业系）」按实际语义拆分或改为「所有伤害 / 物理伤害」。

- **品阶差异项（v0.3）**：每次进阶除统一三围外，额外获得该武将专属词条（暴击率 / 暴击伤害 / 技能增幅，逐阶递增）——逐将表见 §4.5。

### 4.2 倍率口径（v0.3：三围 + 差异项）

- 品阶倍率 = **三围同乘**（攻击 / 射程 / 攻击速度，见 §4.1 表；词条口径见 §0.1）——恢复旧转职「三围」语义；红阶综合 ≈ 攻击 ×1.30 + 射程 ×1.06 + 攻击速度 ×1.08。

## 5. 等级上限 100 与成长重算

### 5.1 经验曲线（分段：前 30 级不变 + 31~100 长尾段）

- L ≤ 30（**完全不变**）：`total(L) = 40×(L−1) + 15×(L−1)×(L−2)`，L30 = **13,340**。
- L ≥ 31（新增长尾段）：每级需求 `need(L) = 420 + 12×(L−30)`；累计 `total(L) = 13,340 + 420×(L−30) + 6×(L−30)×(L−29)`。

| 里程碑 | L30 | L40 | L50 | L60 | L70 | L80 | L90 | L100 |
|---|---|---|---|---|---|---|---|---|
| 累计经验 | 13,340 | 18,200 | 24,260 | 31,520 | 39,980 | 49,640 | 60,500 | **72,560** |

- 节奏校验（口径：4 人队 / 标准难度）：全章经验总量 ≈ 11,127（击杀 ≈9,327 + 参与 ≈1,800），个人分摊 ≈2,782/章；**经验池全投单将 +5,564/章 ≈ 8,346/章** → 主力满级 ≈ **8.7 章里程**；困难（全章 ≈16,826、池 8,413）≈ **5.4 章**；不倾斜（纯自身经验）≈ 17~26 章。
- 设计声明：**经验池倾斜投放是红阶（L100）的关键路径**——红阶定位 = 「跨章毕业目标」（标准全勤 + 池倾斜 ≈ 8~9 章里程；困难 ≈ 6 章）。
- 校准旋钮：长尾段斜率（420 / 12）可整体缩放（建议 ±20% 内调整），不动 1~30 段。

### 5.2 属性成长改百分比口径（v0.3：攻击力口径）

- 新公式（`compute_stats_at` 单点实现，战斗建造与养成面板同源；词条口径见 §0.1）：
  - `攻击力 = round((基础攻击 + 装备固定攻击 Σ) × (1 + attack_pct × (L−1)) × 品阶攻击倍率)` —— 物理系取物理攻击、法系取魔法攻击；装备固定值计入基础攻击（L0）。
  - `射程 = base_range × (1 + range_pct × (L−1)) × 品阶射程倍率`
  - `攻击速度 = base_interval ÷ (1 + speed_pct × (L−1)) ÷ 品阶攻速倍率`（interval 越小越快）
  - `普攻伤害 = 攻击力 × 普攻系数(1.0) → 暴击判定（§5.5）→ 打甲段（NUMBERS 10.12）`
  - `技能输出 = 攻击力 × 技能倍率 × (1 + 技能升级加成) × (1 + 技能增幅) → 打甲段`（不吃暴击，§5.5 / §5.6）
- `attack_pct` 换算规则：旧线性成长率（每级绝对值 ÷ base）按 30→100 级区间等比压缩（压缩系数 ≈0.30），保留各将相对曲线特征；首批取值见 §5.3。
- `range_pct / speed_pct`：**逐将差异项**（v0.3 取消 v0.2 的全员统一 0.10%/级）——近战 / 输出型走攻速，远程 / 辅助型走射程，取值见 §5.3。
- 暴击 / 暴击伤害 / 技能增幅**不进入等级成长**，仅由品阶差异项（§4.5）、装备（§8）、天赋（§10）提供（用户口径）。
- 三属性和品阶三围（§4.2）叠加后，射程满配 ≈ ×1.10~1.18、攻速满配 ≈ ×1.06~1.19（因将而异）；关卡校验随 0.9.7 重测。

> 口径：普攻轴 = 攻击 DPS（攻击 × 攻速，暴击折入）；技能轴 = 单技能值（技能升级 × 技能增幅）。以关羽（攻击 2.7%/级、攻速 +0.08%/级、爆伤轴）为普攻轴样例。

| 品阶（红） | 攻击 ×1.30 + 攻速 ×1.08 → DPS ≈ ×1.40（差异项另计） | 旧二转 ×1.5 × 1.5（伤害 × 攻速）≈ ×2.25 |

### 5.5 暴击（v0.3 新增，普攻轴）

- **适用范围**：仅**普攻**（含范围 / 穿透普攻，逐命中目标独立判定）；**非普攻类技能不吃暴击**；**普攻类真实伤害可以暴击**（真伤只影响打甲段，不影响暴击判定）。
- **基础值**：基础暴击率 **5%**、基础暴击伤害 **150%**；两类来源均**加法**求和（总暴击伤害 = 150% + Σ来源）。
- **结算**：暴击判定通过 → 本次命中伤害 ×（总暴击伤害倍率），乘在打甲前伤害上（与护甲段先后无差）。
- **来源**：品阶差异项（§4.5）、装备（§8）、天赋（§10）、武将被动（§6.2，如赵云「龙胆」暴击率 +25%）——等级成长不提供。
- **上限**：暴击率 clamp ≤ **75%**；暴击伤害不设硬上限、按来源预算控制。
- **无保底**：不做保底计数（普攻样本量大、期望稳定；与护甲「无伤害保底」口径一致）。
- 期望收益口径：暴击 DPS 增益 = 暴击率 ×（暴击伤害 − 100%）。
- 登记：新增「暴击」乘区（普攻专属），0.9.1 先行登记 STATS_PIPELINE 再落代码；暴击可驱动"暴击时触发"类被动（留作后续武将设计空间，本期不启用）。

### 5.6 技能增幅（v0.3 新增，技能数值统一乘区）

- **定义**：独立乘区，作用于**该武将全部非普攻技能数值**：伤害倍率、**友方增益（幅度 / 时长）**、**敌方状态（强度 / 时长）**；**不作用于**普攻、暴击、**状态伤害**（灼烧等固定值，§0.3 B 组红线）。
- **公式**：技能值 = 基准 ×（1 + 3% ×（技能等级−1））×（1 + 技能增幅 Σ）→ 再进入打甲段 / 增益结算。
- **辅助类技能**（刘备 / 貂蝉 / 张飞光环与增益）同口径：+20% 攻速在技能增幅 +10% 时 → +22%（施加方数值）。
- **叠加与上限（用户口径 v0.3）**：**加法求和、不设上限**；与技能升级（≤+27%）乘算，两者不同源、可叠加；实际强度由开发实测调整（§5.4「技能增幅 ×1.26~1.30」为旧预算参考，不再作硬约束）。
- **来源**：品阶差异项（§4.5）、装备套二（§8.5）、天赋（§10）。
- **与既有 `buff_power` 轴的关系**：原「增益强度 / 增益时长」两词条已删除（§0.3 E / F 组），效果统一并入本词条；`buff_power`（L2 科技 / 舞娘职业 / 升阶 buff 步进）保留为**科技侧**独立乘算点，不与技能增幅合并。

## 6. 技能重构（三技能制）

### 6.1 总则

- 每将固定 3 技能：**被动Ⅰ（常驻 / 光环）+ 被动Ⅱ（条件触发或概率释放）+ 大招（怒气 100 驱动）**。
- 与职业彻底解耦：删除 6 职业核心技能 + 12 二转技能 + 职业大招绑定；**大招 = 武将专属**（行为脚本按需复用，§6.3）。
- 数据字段重排：`passive_ids: Array[StringName]`（固定 2 项）+ `ultimate_id: StringName` + `skill_params: Dictionary`（按技能 ID 配参）；删除 `character_skill_id / character_skill_params / trait_id / trait_params / ultimate_override_id`；`rage_gain_mode` 由职业移交武将（职业默认值仅作兜底）。
- 触发钩子沿用 SkillRegistry：常驻光环 / 每波开始 / 漏怪 `on_leak` / 基地低血 / 击杀 / 命中计数；概率类技能的**保底计数按技能参数配置**（如「每 5 次命中必触发 1 次」，沿用旧「稳射」思路），非默认——v0.3.1：张飞「燕人咆哮」不设保底（用户口径）。

### 6.5 技能升级（v0.2 新增；测试口径：上限 10 级）

- 每个技能独立等级 **1~10**（首版测试值，实测后可在 8~10 间收敛）；升级消耗新道具 **「技能升级书」**。
- 消耗曲线（1→10）：**1 / 1 / 2 / 2 / 3 / 3 / 4 / 4 / 5 = 25 本 / 技能**；单武将 3 技能全升 = 75 本。
- 效果：技能值（伤害倍率 / 增益幅度 / 状态强度 / 触发率）= **基准 ×（1 + 3% × (等级−1)）** → Lv10 = ×1.27；大招 / 被动同口径；**时长与范围不受技能升级影响**（时长受技能增幅影响，§5.6）。
- 与技能增幅的关系（v0.3）：两者**乘算**（§5.6）——技能升级只提升该技能本身、技能增幅作用于该武将全部技能；合计 = ×1.27 × 技能增幅（不设限，参考 ≈ ×1.6，§5.4）。
- 解锁与门：仅**已解锁技能**可升级（大招恒可用；被动Ⅰ 需绿阶、被动Ⅱ 需紫阶）；首版不设品阶等级上限（备选：品阶限档 白 3 / 绿 5 / 紫 7 / 黄 8 / 橙 9 / 红 10——见 T-16）。
- 获取：各关首通 / 概率掉落 + 元宝商店（30 元宝 / 本，限购 30）+ 结算转盘（§11）；不进军功商店（保持双店零重叠）。
- UI：技能页每张技能卡显示 **等级（x/10）+ 升级按钮**（技能升级书 图徽 + 数量；书不足 / 技能未解锁时置灰）。

## 10. 天赋系统

### 10.1 点数投放

- 每名武将独立：**L5 起每 5 级 2 点 = 40 点**（L5 / L10 / … / L100 各 2 点）；升级自动获得、分配手动、不可跨武将共享。

### 10.2 三树结构（万国觉醒式：主定位 + 2 功能定位）

- 每将 3 树：主定位树 ×1 + 功能定位树 ×2（树归属见 §3.4 表）。
- 树按定位**共享**（全库 11 棵：6 主定位 + 5 功能定位），每将取其中 3 棵；同一棵树内节点等级**按武将独立存档**。
- 每树 **4 层 / 10 节点 / 20 点容量**：层1 ×3（门槛 0，各 2 级）→ 层2 ×3（本树已投 4 点，各 2 级）→ 层3 ×3（本树已投 8 点，各 2 级）→ 层4 ×1 终极（本树已投 12 点，2 级）。
- 门槛**按"本树已投点数"计**（跨树不互认）——鼓励专精 + 补点；40 点 ≈ 满 2 树（40）或 1 满 + 2 补点。

### 10.3 节点强度预算（每树）

| 层 | 节点数 | 单点强度 | 形态 |
|---|---|---|---|
| 1 | 3（各 2 级） | ≈ +0.6% | 纯数值 |
| 2 | 3（各 2 级） | ≈ +0.6~0.9% | 数值 / 小机制 |
| 3 | 3（各 2 级） | ≈ +0.9% | 机制（触发 / 条件增伤 / 穿透） |
| 4 | 1（2 级） | ≈ +1.5% / 级 + 质变 | 终极 |

- 满树（20 点）≈ **+14%**；40 点全投 ≈ **+25~30%（±5%，待实测）**；整体偏高时一键系数 ×0.8（§5.4）。
- 分桶：数值节点走**局外成长乘区**；机制节点按语义入桶（破甲 → 穿透轴；条件增伤 → 特效 / 30% 池；触发 → 行为登记；**暴击率 / 暴击伤害 / 技能增幅 → §5.5 / §5.6 新桶**）。
- 暴击 / 技能增幅节点预算（v0.3，逐将三树合计）：暴击率 ≤+4%、暴击伤害 ≤+12%、技能增幅 ≤+8%（**节点预算**而非全局上限——技能增幅本身不设限，§5.6；计入 §5.4 三轴预算；关羽样板实配 = 暴击率 +1% / 爆伤 +3%，见 §10.4）。
- 备选（若仍嫌少）：每 5 级 3 点 = 60 点（见 T-17）。

## 15. 防跑偏与验收

### 15.1 防跑偏红线（实现期自检）

- 不做随机词条 / 词条刷取 / 数值随机；武器无品质随机；装备获取确定（首通必得 + 重复 30% 概率；每款上限 3 件，超出转将印 ×2）。
- 不引入系统时钟；商店轮换 = 通关自动刷新 + 手动刷新（元宝 10 起 / +10 / 30 封顶回绕）；不做每日 / 限时商店。
- 不新增 HP 堆叠敌人；武器 / 天赋词条幅度 ≤10~15%（装备特效为预留设计、暂不实装），禁止"装备碾压"式设计。
- 技能升级幅度 ≤30%（Lv10 = +27%）；首版测试上限 10 级。
- 暴击仅普攻（含普攻类真伤）：技能 / 大招 / DoT 不吃暴击；技能增幅作用于非普攻技能全部数值（伤害倍率 / 增益幅度与时长 / 状态强度与时长），不含普攻 / 暴击 / 状态伤害、不含范围（§5.6）。
- 暴击率 clamp ≤75%；技能增幅**加法、不设限**（实际强度以开发实测调整）；装备固定攻击单件 ≤ 职业基础攻击 12%（档位见 §8.4 / §8.5）。
- 词条书写按 §0.2：禁止裸写「伤害」——必须标类型（物理 / 魔法 / 真实）与范围（所有伤害）；条件增伤（对精英 / Boss 等）只出现在技能 / 天赋 / 特效参数（带名与固定值）。
- 材料共享、成长单体锁定：将印 / 精铁 / 乌木共享（三材料均供品阶，§4.3）；品阶 / 天赋点 / 武器归属均按武将单体锁定。
- 主公等级 = 经济轴：只影响商店货档与轮换池，**不提供任何战力加成**；轮换池只投放非唯一性物资，装备 / 信物 / 武将永不入池。
- 数值分桶纪律：品阶 / 天赋数值节点 / 武器数值词条 = **局外成长乘区**（与等级同层）；机制词条按其语义入桶（穿透轴 / 怒气轴 / 范围轴 / 经济轴 / 特效池）——全部登记 STATS_PIPELINE，禁开新乘区口子。
- 单来源 ≤30%（伤害 / 穿甲 / 状态类；技能增幅与暴击伤害除外，见 §5.5 / §5.6）/ 同武将同来源不叠加取最高 / 护甲「先百分比后固定穿透」等既有铁律对新系统一体适用。
- 状态伤害（灼烧 / 中毒等）为面板固定值：不可增加、不可削减（§0.3 B 组）；条件增伤单源 ≤30%（§0.3 C 组特效为预留）。
