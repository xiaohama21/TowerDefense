# 图标系统（ICONS）

> 文档版本：v1.0（2026-11-03）
> v1.0：按用户要求弃用全部旧图标，保留原文件；新版使用原创 SVG 母版转换 PNG，在 0.9.1 分支延伸，目标程序 0.9.1.1 / GDD v0.37.70。
> 隶属 [GAME_DESIGN](../GAME_DESIGN.md)；承载第 13 章图标生产、语义目录与运行时映射。美术分类与许可见 [ART_ASSETS](ART_ASSETS.md)，UI 落位见 [UI_LAYOUT](UI_LAYOUT.md)。

## 1. 范围与旧版处理

- 全部旧 HUD、Kenney UI 图标、光标、Godot 项目图标以及已有 SVG 实验稿保留原路径，标记历史归档。不得覆盖、删除或将其作为新版缺图兜底。
- 本次替换图标资源及文字图标占位；角色头像、Spine 动画、面板与九宫格皮肤按各自素材规则维护。
- 当前运行界面优先全覆盖，已定稿的后续装备、阵营、天赋与商店概念同时备图；备图不代表对应玩法已开发。
- 废弃的转职、碎片、黄巾布、练兵令等功能不恢复。历史设计稿保留原貌，新版图标总览作为当前图标参考。

## 2. 新版资产与生产规范

- 唯一运行目录：`assets/ui/icons/v2/`；光标在该目录 `cursors/` 子目录。SVG 源与 PNG 同目录，语义清单 `manifest.json` 是可用图标目录。
- 原创平滑矢量风，深墨描边、圆角端点、明确剪影，暖金与青玉为通用主色。伤害与状态保留各自色义；形状同时区分语义，避免只依赖颜色。
- 透明背景、无自带底板、无字母／汉字／数字／水印。HUD 单符号控制细节；物品与技能使用更具体的器物与动作符号，禁止用首字代替图标。
- 母版 96×96；PNG 256×256，直接从 SVG 渲染，保留 alpha。15／20／24／34／56px 及亮／暗底两组必须目视检查。光标独立生成 32／64px，热点落在实心像素。
- 六阶品阶统一阶徽轮廓并使用白／绿／紫／黄／橙／红色，增加内部点位帮助区分；战斗 1～9 阶使用独立层级徽记。
- 生成脚本 `tools/generate_icons_v2.py` 写新版目录、新版总览与 build/ 本机哈希快照，不覆盖旧版。采用 Godot 的 SVG 解码器转换 PNG，保证与项目引擎一致；通过 `--godot <可执行文件>` 或 `GODOT_BIN` 指定引擎。
- 原始文件、生成配方、目录台账、透明度／热点／旧版哈希检查与运行截图随仓库保存。
- 完成数量：273 枚 SVG／PNG。HUD 32、状态 12、六品阶 6、战斗阶徽 9、物品 15、军需 6、职业 6、技能／特性 24、定稿被动预备 10、羁绊 2、阵营 4、系统 46、装备预备 60、科技 32、光标 9。光标另含 64px 双倍图，项目徽章另有 Windows ICO。

## 3. 语义清单与接入

| 类别 | 覆盖范围 | 使用位置 |
|---|---|---|
| HUD／数值 | 原 21 枚、暴击率／爆伤／技能增幅、怒气／限次／锁、冷却／生命／弹道／溅射等已定义属性 | 战斗、养成、百科、经济与奖励 |
| 阶徽 | 六阶武将、九阶战斗层级 | 武将卡、品阶弹窗、战场角标 |
| 物品 | 三材料、技能书、求贤令、五遗物、五信物 | 背包、编队、养成、百科、奖励 |
| 军需 | 修整／火攻／擂鼓／缓兵／掷石齐射／犒军 | 军需处、局内军需列表与带槽 |
| 技能 | 六职业大招、九角色专属技能、九现有特性；已定稿被动预备图 | 养成与百科技能列表 |
| 系统 | 导航／设置／确认／关闭／箭头／星标／菜单／音量等、六职业、阵营与装备预备图 | 功能按钮、筛选、主菜单与项目图标 |
| 光标 | 默认、手型、拖拽、十字、禁建、编辑器三类笔刷及备选指针 | 游戏与地图编辑器 |

- `UITheme.hud_icon()` 仅查询新版目录；缺失仍返回 null，由控件画虚线圆，不回退旧素材。
- `ConceptIcon` 承载统一图标控件；物品按 item_id，军需按 `supply_`＋supply_id，技能按原 id，特性按原 trait_id 查询。
- 按钮／下拉菜单的图标纹理必须按目标像素重采样，不能将 256px 源直接作为最小尺寸。局内军需的效果、费用与限次同军需处使用图徽＋数值；常驻特性在养成与百科均可查看。
- 旧 Kenney 硬编码图标引用、默认控件箭头与复选图标切到新版；光标仍经 CursorIcons 唯一出口注册。
- 图徽旁不重复资源／属性／状态名词，数值与单位保持可读，解释放 tooltip；动作文字保持。
- 导出排除旧 `assets/ui/icons/` 根图标、`icons_hud/`、旧光标与 `icon.svg`，保留新版目录。

## 4. 缺口与验收

- 完整语义目录由生成的 manifest 与总览表登记，生成完成后逐项检查，不以空文件或同一占位符充数。
- 验收：所有当前资源 id 与硬编码图标可解析；PNG 全部透明且主体不切边；SVG 可以由 Godot 解析；光标两档尺寸与热点有效；旧文件哈希不变。
- 回归至少 PackVerify／Smoke／Flow／ExitFlow／Rank／SupplyState／DevelopRefresh；新图标图集与养成／百科／编队／军需／战斗截图目视验收。
- 当前状态：273 枚生成与运行接入完成，当前资源图标缺口为 0；预备图不代表玩法落地。透明度／尺寸／剪裁／当前资源覆盖／光标热点校验均通过。
- 旧图保留：`legacy_archive.json` 固化 168 个已跟踪旧文件哈希；本机原始 290 文件（含未跟踪实验稿和导入元数据）快照留在忽略的 `build/icons_v2_legacy_workspace.json`，本轮逐项保持不变。便携仓库校验不依赖本机未提交文件。
- 总览：[完整 HTML](../ui_concept/icons_v2.html)、[重点亮暗底预览](../ui_concept/icons_v2_preview.png)、[目录校验](../ui_concept/icons_v2_verification.json)。`IconPreviewRunner` 隔离档案截图归档于 `docs/ui_concept/runtime_0.9.1.1/`，涵盖主菜单、地图、军需、背包、科技、养成三页、百科三页、设置、编队与战斗。
- Windows 发布：文件／PE 版本 0.9.1.1，独立模板启动退出码 0；引擎从发布 EXE 挂载 PCK 后加载全部 273 枚图标、主菜单启动并截图，旧图不可加载。工具 `verify_icons_v2_export.gd` 必须在无源文件的 `build/` 工作目录运行，避免读取开发资源兜底。
- 回归通过：PackVerify／Smoke／Flow／ExitFlow／Rank／TechUnlock／SupplyState／DevelopRefresh／GoldFx／MapEditor；既有退出音频与 MapEditor 资源告警继续观察，图标及功能断言全部通过。
