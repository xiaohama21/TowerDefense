## 7.2 掉落规则

- **首通必掉**：`first_clear_rewards`（已有机制）；s08 首通另含求贤令×3（v0.14.1；**v0.30.0 随抽将暂时移除**）。**信物首通必掉（✅ 0.8.14.0 落地）**：标准难度 s08 首通 → 「天公雷诏」（`StageData.first_clear_relic`）；困难难度 s08 首通 → 「太平要术·残卷」（`StageData.first_clear_relic_hard`）；**各难度各 1 件、每件仅获取 1 次**（`PlayerProfile.add_relic` 去重，重复通关不再掉落）；不做"先通困难补标准"补发逻辑（困难解锁本就要求标准通关）。原 s08 首通关羽信物掉落已被本方案替换。
- **重复通关固定奖励**：三材料逐关投放，配置见 §7.4；黄巾布投放已删除。
- **概率掉落表**：`StageData.probability_drops` 逐条独立判定；材料／技能书配置见 §7.4。信物不进概率池，s08 按难度首通唯一获取。
- **军功掉落（2026-09-10 定稿，✅ 0.8.16.0 落地）**：**击杀掉落固定值**（步卒/弓手 1、轻骑/祭酒 2、力士/伍长及 5 类新精英 3、Boss 25、终 Boss 张角 **40**（2026-09-13 拍板）），困难难度 ×1.5；**失败/退出不带出**（与经验同结算语义）。用途 = 军需**解锁 / 强化**（见 NUMBERS 10.15）；不进概率掉落表、不走商店、不占背包物品位（作为货币余额写档，见 SAVE_DATA 8）。
- 固定与概率掉落数量均按难度材料倍率缩放（`Difficulty.material_mult`：标准 ×1.0 / 困难 ×2.0（v0.31.2 移除轻松），取整保底 ≥1，v0.14.1）。
- **结算转盘（已实现）**：胜利剩余金币 ≥150 可抽一次，五项奖池见 §7.4；入账失败可重试，成功锁定，奖励即时原子写盘。
- 掉落数据全部走 `ItemAmountData` / 资源配置。

## 7.3 抽奖（求贤）（✅ v0.14/v0.14.1 已实现；⏸ v0.30.0 暂时移除——入口/掉落已关闭，GachaService 与存档字段保留，恢复时恢复入口与 s08 掉落即可）

- 入口：养成面板"求贤"行（v0.14.1，v0.30.0 移除），消耗求贤令×1 抽一次；求贤令来源为 s08 首通奖励×3（已随 v0.30.0 移除；后续章节/活动【远期】）。
- 卡池（`GachaService`）：**已拥有的武将**（重复抽出 → 碎片 20）。未拥有的主线武将不在常规池；**保底不绕过主线**——未通关其解锁关（`unlock_stage_id` 对应 `first_clear` 关卡）的武将不可被保底抽出。
- 保底：累计第 10 抽（`gacha_state` 计数）必得一个可保底的未拥有角色；全员已拥有或全部被主线锁定时**不产出碎片**（原折算碎片 40 已随 0.8.14 删除，返回空保底标记）。
- 重复角色 → 碎片（`shards`）；碎片用途：信物兑换（升星已随 v0.30.0 暂时移除，见 CHARACTERS.md 4.8），**不再抵扣转职材料**（v0.11 已废）。**✅ 碎片用途已随信物重构整体删除（0.8.14.0 落地）**——兑换（60 碎片/件）/ 结算转盘产出 / 保底折算 / Debug 发放全部废止，存档 `shards` 字段随 schema v4 迁移清理。
- **铁律**：抽奖不产出主线关键角色、不卡主线进度（保底过滤未通关解锁关角色）。
