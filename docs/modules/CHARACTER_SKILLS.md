## 1. 定位与原则

- **角色技能 = 武将专属差异化能力**，主题来自《三国演义》人物自身特点（典故驱动），与职业技能/职业大招**解耦**——不依赖职业层触发、不共享职业层乘区；仅允许怒气资源类间接关联。
- **类型**：
  - **A 主动小技能**：冷却制、不耗怒气/金币；**就绪后自动释放**（v0.5 / 0.8.11.0 起移除手动释放入口——塔详情面板技能区删除，手动大招开关仅约束大招本身）。
  - **B 条件触发被动**：多为"每波一次"的局内事件触发（漏怪、基地低血等）。
  - **「可手动」登记制（v0.6 定稿）**：默认全部自动；需手动入口的技能必须先登记（冷却 / 目标类型 / 期望槽位），不登记不开发入口；手动收益 ≤10~15%、通关不依赖（覆盖非门槛）。
- **强度预算独立**：普攻 / 职业技能 / 大招 / 角色技能分预算（NUMBERS.md 10.x 原则），数值保守、全部待实测，防过强或过弱。
- **数据与实现**：`CharacterData` 新增 `character_skill_id` + `character_skill_params`（复用 `skill_params` 模式）；行为分发进 `SkillRegistry`（新增角色技能钩子：漏怪 `on_leak`、基地低血、每波开始、冷却就绪）。

## 4. 单体技能真伤化与伤害描述（2026-09-09 拍板，排期 0.8.13.0）

- **原则**：为打破"重甲无单点解"，将少量单点/处决语义的技能设为**真实伤害**（无视护甲、不可被任何减伤）；其余保持物理/魔法，依来源在 `take_damage` 标类型。
- **关羽·青龙偃月**：`2.5×` 单体，**真实伤害**；击杀返 CD 6s 保留，定位 = "重甲单点斩"。
- **黄忠·定军山**：保持物理 + 定军易伤标记（定位 = 铺普攻易伤，不转真伤）。
- **全量伤害描述标注伤害类型**（物理/魔法/真实）：本节技能表、图鉴、飘字/演出、军需与遗物文案一并改写；职业技能/大招真伤登记见 BEHAVIORS B.3.5，数值见 NUMBERS 10.12。
- 本改动属 0.8.13.0（`take_damage` 类型分流）落地范围；当前 `.tres` 的 `character_skill_params` 不预改，待代码排期执行。
