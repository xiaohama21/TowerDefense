## 1. 定位与原则

- **角色技能 = 武将专属差异化能力**，主题来自《三国演义》人物自身特点（典故驱动），与职业技能/职业大招**解耦**——不依赖职业层触发、不共享职业层乘区；仅允许怒气资源类间接关联。
- **类型**：
  - **A 主动小技能**：冷却制、不耗怒气/金币；默认满冷却自动释放，可选手动（沿用大招手动开关先例）。
  - **B 条件触发被动**：多为"每波一次"的局内事件触发（漏怪、基地低血等）。
- **强度预算独立**：普攻 / 职业技能 / 大招 / 角色技能分预算（NUMBERS.md 10.x 原则），数值保守、全部待实测，防过强或过弱。
- **数据与实现**：`CharacterData` 新增 `character_skill_id` + `character_skill_params`（复用 `skill_params` 模式）；行为分发进 `SkillRegistry`（新增角色技能钩子：漏怪 `on_leak`、基地低血、每波开始、冷却就绪）。

## 3. 实现清单（排期阶段 8·提交 6）

- 数据：`CharacterData` 新增角色技能字段；9 名武将 `.tres` 配置技能 ID 与参数。
- 钩子：`SkillRegistry` 新增角色技能分发与触发钩子（漏怪/基地低血/每波开始/冷却就绪）；`GameManager` 漏怪事件透出。
- UI：主动技能按钮 + 冷却盘（塔属性面板，沿用大招手动释放先例）；技能说明文本（图鉴/养成页签）。
- 演出：复用飘字/扩散环/音效管线（v0.15/v0.16 已建）。
- 数值：全部待实测校准（强度预算独立）；9 名武将全部开发（✅ v0.27.4 拍板取消 3~4 名试点）。
