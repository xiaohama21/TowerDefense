## 1. 胜利经济与等级

元宝首通30、重复10，困难×2；主公经验首通80、重复25，困难×1.5后四舍五入（120/38）。首通按全局关卡首次完成，仅一次，不按难度再领首通。失败/放弃/未保存不带出；奖励、等级、商店自动刷新和现有战利品同一次原子提交，重复run_id不重复奖励或刷新。元宝不进转盘与随机掉落。

主公初始L1，经验0、元宝0；主公只影响货档，无战斗属性。升至L+1需求30+5×(L−1)，累计到L100=27225，上限100，达到上限后经验封顶。旧档新字段缺失补0，不补发已完成关卡首通奖励；有效余额/经验与商店状态保留，非法数值非负化、有限值夹取。酒馆初始100元宝归0.10.2。

## 3. 轮换与防重复操作

三个轮换槽从当前解锁物资池抽取，同屏不重复。Ⅰ档仅两种商品，显示两件+第三格虚线空位（规则短句：升至Lv.10后补齐），禁止复制商品凑三件；Ⅱ档起满三件。轮换商品可不限次买，装备/信物/武将不进轮换。

新档/迁移初始化两种Ⅰ档商品，读档不随机重掷。每次成功胜利免费刷新一次，手动价序10→20→30→10，成功胜利重置为10；升级跨货档时本次刷新至少包含一件新档商品（同次胜利只刷新一次）。失败/存档失败不改货架、价格或计数。纯读档/切页不刷新。

shop_state={permanent_counts, rotation, refresh_step, revision}。revision随成功买入/手动刷新/胜利刷新递增；UI传当前revision与商品ID，服务器式本地事务再次核对当前货架、门槛、余额、限购与库存。旧点击、未知ID、非当前轮换项拒绝，不扣钱。SaveManager在档案副本上执行并原子保存，失败不改变活档；退出只读/高版本保护继续生效。

## 4. 界面与验收

大厅新增商店入口，军需入口保留；八入口共用紧凑46px导航。顶栏主公图徽+Lv与经验进度，元宝/军功图徽+余额，六档进度；两子页用货币图徽切换。元宝左栏常驻列表可纵向滚动，右栏三格轮换与刷新价；商品以图徽+数量与效果图徽展示，名称在tooltip，购买动作常显。锁定条目显示Lv门槛/通关规则，限购或库存满显示已满/已购；存档失败短句提示。百科/背包商品来源补充商店。地图奖励预告与胜利结算新增元宝和主公经验图徽数值，结算显示主公升级提示。

元宝ingot、主公lord_level与主公经验lord_exp暂无独立图徽，运行使用虚线圆占位并登记ART_PROMPTS、ICONS与src/README，不用金币/武将经验图徽冒充。

地图4×2卡片的简介收为一行，完整简介由底部关卡预告条承载；全部奖励图徽保留且位于卡片边界内。切换标准/困难时卡片与预告条同时更新经济数值，一键通关按当前所选难度结算。返回地图读取最新档案。装备商品显示规则短句「通关sNN·关卡名后解锁」，背包物资/永久遗物详情显示对应商店获取规则，装备详情沿WeaponRegistry来源提示。

验收覆盖：v9→v10和高版本只读、负值/非有限值/未知项、两货币隔离、全货档边界、初始两格与升档保底、刷新回绕与胜利重置、永久限购与旧遗物、装备关卡门槛/3件上限、保存失败回滚、重复点击/run_id；源窗口和打包程序验收，既有技能/装备/流程回归。
