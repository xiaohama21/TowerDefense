# 数值基调（NUMBERS）

> 隶属《烽火连营·三国塔防》设计文档体系，总纲见 [../GAME_DESIGN.md](../GAME_DESIGN.md)。
> 承载总纲原章节：5.3（经济规则）与 10（数值基调）。章节编号沿用全局稳定 ID。
> 所有数值以 `.tres` 配置为准，本文仅作制作参考，允许在平衡调整中修改，但修改必须同步更新本文档。
> **数值配置中心化（✅ v0.18.0）**：全局平衡数值统一在 `resources/balance/game_balance.tres`（`BalanceData`：经验曲线、等级上限、难度倍率、局内升级步进、怒气上限、敌人特殊行为参数），代码经 `GameBalance` 只读引用，不再硬编码；科技树条目在 `resources/tech/tech_tree.tres`（`TechItemData`）。关卡/角色/敌人自身数值仍走各自 `.tres`。

## 5.3 经济

- 收入：初始金币 + 击杀奖励（`currency_reward`）+ 波次完成奖励（`completion_currency`）。
- 支出：建造（`build_cost`，第一章 50~80 区间）、局内塔升级（见 modules/STAGES.md 5.4）、转职材料（局外）。
- **波次完成奖励（✅ v0.25.0 阶段 8·提交 2 启用）**：s04~s08 配置 `completion_currency=10`（每波完成 +10 金，占总收入 ≤10~15%）；其余关卡仍为 0；后勤科技"波次奖励 +20/40%"联动（v0.26.0 接入）。
- 数值基调：一关总金币收入约等于"可建造 6~9 座塔 + 若干次升级"，保证不卡关也不无限铺塔（详见 10.3）。

## 10.1 等级与经验

- 等级 L 所需累计经验：`total_exp(L) = 40*(L-1) + 15*(L-1)*(L-2)`（L≥1）。
- 示例：10 级 ≈ 1440 经验，20 级 ≈ 5890，30 级 ≈ 13340。
- 单局经验估算：黄巾步卒 8 / 轻骑 10 / 伍长 25，一关约 300~500 击杀经验 + `participant_xp`（50，每名出阵武将各得一份）。
- 节奏目标：**1~10 级约需 3~5 次通关**，即玩家打完第一章前半即可开始第一次转职。
- **节奏校准（v0.7）**：上述目标按"经验集中于单人"估算。按 4.4 归属规则分摊后，4 人编队均势时个人约占队伍总经验的 25%（`kill_xp` 总量守恒），叠加参与经验后个人每关约得 150~200 经验，10 级约需 7~10 关。若阶段 1 实测偏慢，优先上调 `participant_xp` 或敌人 `kill_xp`，其次调整经验曲线；以"主力武将"的节奏为准校验，不以全员同步升级为目标。
- 经验归属规则本体见 [CHARACTERS.md](CHARACTERS.md) 4.4。

## 10.2 属性成长

- 每级伤害成长：`damage_growth_per_level`（现有角色 2.0~5.5）。
- 每级射程成长：`range_growth_per_level`（默认 0，保持位置规划稳定）。
- **应用公式（v0.10 落地，`CharacterData.compute_stats_at()`）**：伤害 = `(base_damage + damage_growth_per_level × (等级−1)) × 转职伤害倍率`；射程/攻速同理（攻速为 interval 乘法，越小越快）。战斗建造与养成界面共用同一实现，保证两处所见一致。
- 职业乘数（相对角色基础属性）：见 [PROFESSIONS.md](PROFESSIONS.md) 4.2.1 资源清单。
- 转职倍率：`PromotionData` 的 damage/range/interval 乘数，v0.10 已全部配置（见 [CHARACTERS.md](CHARACTERS.md) 4.5 表；现有关羽一转：伤害×1.2、攻速×0.9）。

## 10.3 经济

- 建造价格区间：50~80（现有：刘备 55、关羽 70、黄忠 65、貂蝉 60、张飞 60、皇甫嵩 75）。
- **初始金币基调：180（v0.9.1 平衡调整，此前 100）**。依据：100 只够开局单塔，第 1~2 波对基础兵必然漏怪（单塔 DPS 与 0.8s 进场间隔不匹配）；180 = 初始两名武将（125）同时部署 + 缓冲，且不触及终局总量——造价区间与击杀奖励不动，避免"6~9 塔"校准失效。
- 三关收入复核（初始 180 后）：s01 ≈ 653、s02 ≈ 881、s03 ≈ 821，仍落在"6~9 塔 + 2~3 次升级"区间上沿；开局放松、终局总量不变。
- 击杀奖励：炮灰 10、常规 12、精英 25。
- 局内升级费用与回收返还：见 modules/STAGES.md 5.4。
- 目标：每关总收入 ≈ 建造 6~9 座塔 + 2~3 次局内升级。若实测中盘仍然吃紧，下一个调整旋钮是击杀奖励（炮灰 10 → 12），而非建造费用。

## 10.4 转职消耗

- 一转（v0.10 配置）：10 级 + 黄巾布×10。
- **材料收入配套（v0.10/v0.13/v0.14.1）**：重复通关固定奖励黄巾布×2（s01~s03）；s06~s08 概率掉落表黄巾布×3@50%（`DropEntryData` 逐条掷点）；s08 Boss 首掉关羽信物 + 首通求贤令×3。固定与概率掉落均按难度材料倍率缩放（`Difficulty.material_mult`）。
- **升星消耗（v0.13）**：逐星碎片 20/40/80/160（1~4→2~5 星）；信物兑换 60 碎片。碎片产出：求贤重复武将（阶段 4 提交 2），此前仅调试通道。
- 二转【远期】：20 级 + 章节材料（tier2）+ 碎片。

## 10.5 怒气与大招数值（初稿）

- 怒气上限 100；输出职业：命中 +4、每 10 点伤害 +1；辅助职业：触发增益脉冲 +4、每覆盖一名友方再 +2（`support_ultimate_gain_per_tick`×友方数，v0.11.2 落地）。
- 大招无冷却、怒气满即自动释放；目标节奏：**一关内每名武将释放 3~6 次大招**。
- 强度基调：骑兵大招 ≈ 3 次普攻单体伤害（斩杀返还怒气）；虎贲大招（破阵）≈ 攻击范围内敌人受到 1.5 次普攻伤害并击退一段距离 + 附近友方攻速 +15%/5s（激励段，v0.27.2 新增）；弓箭手大招 ≈ 4 箭连射；术士大招 ≈ 2 次普攻的范围总量 + 减速 40% 持续 2 秒；舞娘大招 ≈ 全队攻速 +30% 与伤害 +15%，持续 8 秒。
- **局内升级大招倍率（v0.7 补 5.4 引用）**：大招伤害/效果按 `1 + 0.25 × battle_level` 放大（与普攻升级的 +25%/级同步），再乘转职 `ultimate_multiplier`；大招的怒气获取规则不随局内等级变化。
- **释放模式（✅ v0.15.0）**：默认怒气满 100 自动释放；设置面板"大招手动释放"开启后（持久化 settings.cfg），满怒改为提示（怒气条金色脉动），选中塔后在属性面板点"释放大招"或按 R 键释放（须满怒且射程内有目标，否则保留怒气）。
- **转职技能数值（✅ v0.15.0；v0.27.1 收敛为 6 职业技能）**：技能基准值与档位规则见 CHARACTERS.md 4.5 技能表；档位系数 `s = 1 + 0.1 × min(battle_rank / 5, 4)`（✅ v0.27.4 拍板：仅职业技能、按局内升阶 `battle_rank`；每 5 档 +10%、上限 4 档 +40%），数值不另设独立平衡表，随档位线性缩放；角色技能与档位无关（见 CHARACTER_SKILLS.md）。
- 转职强化：一转大招倍率 1.2（示例）。

## 10.6 贡献事件经验数值（v0.11 新增，阶段 3 与怒气同源实现）

按 `combat_role` 决定计入项（规则见 [CHARACTERS.md](CHARACTERS.md) 4.4）；数值为初稿：

| 事件 | 计入经验 | 说明 |
|---|---|---|
| 击杀（最后一击） | `kill_xp` × 50%（向上取整） | 现行规则保留 |
| 伤害参与 | 击杀经验 50% 均分 | 按有效伤害均分；辅助类权重 ×0.5 |
| 增益施加 | +4/次 | 辅助类计入（buff 生效瞬间） |
| 光环覆盖 | +2 / 5秒 / 友方 | 辅助类计入（覆盖时长折算） |
| 治疗/减益（未来） | +1 / 10 点效果量 | 远期 |

- **落后补正**：武将等级低于编队平均 1 级以上时，其经验获取 +20%/级差（上限 +60%）。

- **防刷限制（v0.23.0 拍板）**：光环覆盖按时间分段结算（不按每帧）；同一增益对象短时间内重复刷新不重复给满额贡献；辅助贡献经验设置**每波上限**（初稿：不超过本波击杀经验总额的 1.5 倍，待平衡），避免辅助塔挂机超越输出塔。
- 目标：辅助类与输出类的单局经验差距 ≤ 30%（当前纯伤害归属下差距 2~3 倍）。

## 10.7 科技树与难度倍率（v0.11 新增，阶段 4）

**科技树**：全局永久加成，大厅"科技"页签消费。
- 科技点获取（✅ v0.14.1 全链路）：每关首次通关 +2、重复通关 +1，按难度材料倍率缩放（轻松 ×0.8 / 标准 ×1.0 / 困难 ×2.0）；`BattleSession.pending_tech_points` → 胜利提交写档。
- 三分支实现值（✅ v0.14.1 落地；**v0.26.0 重构为四类 31 项**）：**经济**（初始金币 +20/40/60）、**军事**（全武将伤害 +2%/4%/6%）、**基建**（基地生命 +1/2/3）；建造位解锁费用由 `BuildSlotData.unlock_cost` 按关配置（50~80/个，见 STAGES.md 5.1），不纳入科技加成。
- **四类分类（✅ v0.26.0，阶段 8 提交 3）**：**军略**（全武将伤害 3 项 + 六职业分支各 2 级，职业伤害/攻速/buff 效果 ≤10%）、**后勤**（初始金币 3 项 + 波次奖励 20/40%）、**工事**（基地生命 3 项）、**将略**（积怒/回收率/升阶折扣/军需折扣各 2 级 ≤10%）；`TechPanel` 四页签 + 摘要列表 + 点击详情；封顶按 10.7 原则（伤害 ≤15%、职业/机制 ≤10%、波次奖励 ≤40%）。
- **上限原则：全局加成合计不超过 ±15% 强度**——科技树是"刷关价值的兑现"，不是数值通胀的出口；与难度设定（见下）互为对冲。

- **科技重置（✅ v0.26.0 落地，v0.23.0 拍板）**：允许**无条件重置**——免费、不限次数、全额返还科技点（不做 80% 折损）；已解锁科技不丢失、仅迁移到新分类（阶段 8 提交 3 迁移时适用）。

**难度设定（✅ v0.14/v0.14.1）**：选关时选择（默认标准；困难需该关标准通关后解锁），结算按难度分键写入 `stage_progress[].difficulties`，困难解锁读取标准通关记录。

| 难度 | 敌人 HP/伤害 | 击杀奖励/经验 | 材料/科技点 |
|---|---|---|---|
| 轻松 | ×0.8 | ×0.8 | ×0.8 |
| 标准 | ×1.0 | ×1.0 | ×1.0 |
| 困难 | ×1.4 | ×1.6 | ×2.0 |

目的：容纳养成通胀（科技+升星+信物），给重复游玩一个"更高回报"的选择器。

## 10.10 全系统数值计算顺序与上限（v0.22.0 拍板）

**统一计算顺序**（防止多系统叠乘指数膨胀）：

```text
基础属性
→ 局外成长：等级 / 转职 / 星级 / 信物
→ 编队加成：羁绊 / 科技
→ 本局开局加成：遗物
→ 本局动态加成：升阶 / 军需 / 技能 / 大招
→ 最终伤害、攻速、射程限幅
```

**硬规则**：

- 同类光环**可叠加（加法）**，但设总上限——全局加成合计 ≤±15%（沿用 10.7）；局内同类增益合计上限初稿 ≤+100%，待平衡验证。
- 同类减速不叠加，只刷新持续时间。
- 最终攻速倍率下限 `0.55`（拍板采用，合理性待实测验证）。
- 普攻、技能、大招分别设置强度预算，不允许所有效果共用无限乘区。
- AOE 半径、击退距离和控制持续时间设置上限（随职业/阶段定值，阶段 9 前补全）。

**每关经济预算**（v0.22.0 拍板；基准=标准难度/无遗物/无科技加成；`StageData` 待补预算字段）：

```text
初始金币 / 预计击杀金币 / 波次奖励 / 技能额外金币 / 遗物额外金币
理论总收入 / 推荐建造数 / 推荐升阶次数 / 推荐军需次数 / 通关时合理剩余金币
```

每关必须满足：

- 不购买军需也存在可行通关方案（标准难度）。
- 军需应改变解法，高难度下为"不可或缺"的重要道具，而非标准难度的必买按钮。
- 升阶和追加建塔之间存在真实取舍。
- 回收不能通过重复建造获得正收益。

**失败/退出/崩溃语义**（v0.22.0 拍板）：

- 进入战斗：不再消耗遗物（改为胜利结算后消耗）。
- 战斗中：经验、升阶、军需、金币只存在 `BattleSession`。
- 胜利：一次性提交 XP、掉落、解锁、科技点、关卡进度，并扣除已选带遗物各 1 件。
- 失败 / 重开 / 退出：丢弃 `BattleSession` 临时内容，遗物不消耗。
- 应用崩溃：下次启动不恢复未提交战斗，遗物不消耗。
- `run_id` 保证重复胜利信号只产生一次奖励。

## 10.11 P2 玩法体验数值（v0.24.0 拍板）

**挑战目标奖励**（阶段 10 排期，未开发；全局 3 目标：不使用军需通关 / 基地生命 ≥80% 通关 / 击败全部精英）：
