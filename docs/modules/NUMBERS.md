## 5.3 经济

- 收入：初始金币 + 击杀奖励（`currency_reward`）+ 波次完成奖励（`completion_currency`）。
- 支出：建造（`build_cost`，第一章 50~80 区间）、局内塔升级（见 modules/STAGES.md 5.4）、转职材料（局外）。
- **波次完成奖励（✅ v0.25.0 阶段 8·提交 2 启用）**：s04~s08 配置 `completion_currency=10`（每波完成 +10 金，占总收入 ≤10~15%）；其余关卡仍为 0；后勤科技"波次奖励 +20/40%"联动（v0.26.0 接入）。
- 数值基调：一关总金币收入约等于"可建造 6~9 座塔 + 若干次升级"，保证不卡关也不无限铺塔（详见 10.3）。

## 10.1 等级与经验

- 等级 L 所需累计经验：`total_exp(L) = 40*(L-1) + 15*(L-1)*(L-2)`（L≥1）。
- 示例：10 级 ≈ 1440 经验，20 级 ≈ 5890，30 级 ≈ 13340。
- 单局经验估算：黄巾步卒 8 / 轻骑 10 / 伍长 25，一关约 300~500 击杀经验 + `participant_xp`（50，每名出阵武将各得一份）。
- 节奏目标：**1~10 级约需 3~5 次通关**，即玩家打完第一章前半即可开始第一次转职。
- **节奏校准（v0.7）**：上述目标按"经验集中于单人"估算。按 4.4 归属规则分摊后，4 人编队均势时个人约占队伍总经验的 25%（`kill_xp` 总量守恒），叠加参与经验后个人每关约得 150~200 经验，10 级约需 7~10 关。若阶段 1 实测偏慢，优先上调 `participant_xp` 或敌人 `kill_xp`，其次调整经验曲线；以"主力武将"的节奏为准校验，不以全员同步升级为目标。
- **经验池（2026-09-10 定稿、排期 0.8.15）**：胜利结算按 **50% 额外注入**经验池——`注入 =（本局击杀经验总量 + participant_xp × 出战人数）× 50%`（不扣武将自身所得）；池内经验可自由分配给任意已拥有武将（不可逆、二次确认），失败 / 退出 / 崩溃作废；**练兵令删除**、养成面板改"直接升级"。各关注入测算与追赶节奏见 10.14，规则见 [CHARACTERS.md](CHARACTERS.md) 4.4、决策见 DESIGN_REVIEW §12.6.1。
- 经验归属规则本体见 [CHARACTERS.md](CHARACTERS.md) 4.4。

## 10.2 属性成长

- 每级伤害成长：`damage_growth_per_level`（现有角色 2.0~5.5）。
- 每级射程成长：`range_growth_per_level`（默认 0，保持位置规划稳定）。
- **应用公式（v0.10 落地，`CharacterData.compute_stats_at()`）**：伤害 = `(base_damage + damage_growth_per_level × (等级−1)) × 转职伤害倍率`；射程/攻速同理（攻速为 interval 乘法，越小越快）。战斗建造与养成界面共用同一实现，保证两处所见一致。
- 职业乘数（相对角色基础属性）：见 [PROFESSIONS.md](PROFESSIONS.md) 4.2.1 资源清单。
- 转职倍率：`PromotionData` 的 damage/range/interval 乘数——**旧角色绑定模型（v0.10~v0.28 前 11 个角色 promotion）已废弃**；v0.28.1 按职业级转职树统一配置（6 一转 + 12 二转 = 18 节点，三围 + 大招倍率，等效 DPS 预算一转 ×1.2~1.33 / 二转强化线 ×1.44~1.59 / 二转新技能线 ×1.39~1.44 + 新技能，见 [SKILLS.md](SKILLS.md) 4.1）。**✅ 提交 8（v0.33.0 / 0.8.8.0）**：18 节点数值对照 4.1 三张表复核一致；倍率以未转职为基准、只应用 `promotion_path` 末位、不链式相乘（SmokeRunner 专项断言）。

## 10.3 经济

- 建造价格区间：50~80（现有：刘备 55、关羽 70、黄忠 65、貂蝉 60、张飞 60、皇甫嵩 75）。
- **初始金币基调：180（v0.9.1 平衡调整，此前 100）**。依据：100 只够开局单塔，第 1~2 波对基础兵必然漏怪（单塔 DPS 与 0.8s 进场间隔不匹配）；180 = 初始两名武将（125）同时部署 + 缓冲，且不触及终局总量——造价区间与击杀奖励不动，避免"6~9 塔"校准失效。
- 三关收入复核（初始 180 后）：s01 ≈ 653、s02 ≈ 881、s03 ≈ 821，仍落在"6~9 塔 + 2~3 次升级"区间上沿；开局放松、终局总量不变。
- 击杀奖励：炮灰 10、常规 12、精英 25。
- 局内升级费用与回收返还：见 modules/STAGES.md 5.4。
- 目标：每关总收入 ≈ 建造 6~9 座塔 + 2~3 次局内升级。若实测中盘仍然吃紧，下一个调整旋钮是击杀奖励（炮灰 10 → 12），而非建造费用。

## 10.5 怒气与大招数值（初稿）

- 怒气上限 100；输出职业：命中 +4、每 10 点伤害 +1；辅助职业：触发增益脉冲 +4、每覆盖一名友方再 +2（`support_ultimate_gain_per_tick`×友方数，v0.11.2 落地）。**命中口径（v0.31.4 / 程序 0.8.6.2）**：命中 = 实际造成伤害后（近战即时、弹道命中结算；弹道飞行中目标死亡/丢失或空爆不积怒，原远程发射时提前计入已修正）；AOE 每发命中一次按该发伤害计，不按命中数叠加；大招/主动技能弹道不积怒。
- 大招无冷却、怒气满即自动释放；目标节奏：**一关内每名武将释放 3~6 次大招**。
- 强度基调：骑兵大招 ≈ 3 次普攻单体伤害（斩杀返还怒气）；虎贲大招（破阵）≈ 攻击范围内敌人受到 1.5 次普攻伤害并击退一段距离 + 附近友方攻速 +15%/5s（激励段，v0.27.2 新增）；弓箭手大招 ≈ 4 箭连射；术士大招 ≈ 2 次普攻的范围总量 + 减速 40% 持续 2 秒；舞娘大招 ≈ 全队攻速 +30% 与伤害 +15%，持续 8 秒。
- **局内升级大招倍率（v0.7 补 5.4 引用；✅ 提交 8 效果型接入）**：大招伤害/效果按 `1 + 0.25 × battle_rank` 放大（与普攻升阶的 +25%/阶同步），再乘转职 `ultimate_multiplier`；大招的怒气获取规则不随局内等级变化。**效果型大招（鼓舞/破阵激励段）同样乘转职 `ultimate_multiplier`**（`Tower.ultimate_effect_power()`，B-018 修复；升阶效果步进仍走 buff power 倍率，不重复乘伤害步进）。
- **释放模式（✅ v0.15.0）**：默认怒气满 100 自动释放；设置面板"大招手动释放"开启后（持久化 settings.cfg），满怒改为提示（怒气条金色脉动），选中塔后在属性面板点"释放大招"或按 R 键释放（须满怒且射程内有目标，否则保留怒气）。
- **转职技能数值（✅ v0.15.0；v0.28 重构为 6 职业核心技能 + 二转双轨（强化 `+` / 新技能））**：技能基准值与档位规则见 [SKILLS.md](SKILLS.md) 第 2 节；档位系数 `s = 1 + 0.1 × min(battle_rank / 5, 4)`（✅ v0.27.4 拍板：仅职业技能、按局内升阶 `battle_rank`；每 5 档 +10%、上限 4 档 +40%），数值不另设独立平衡表，随档位线性缩放；角色技能与档位无关（见 CHARACTER_SKILLS.md）。
- 转职大招倍率：以 SKILLS.md 4.1 三张表为准（一转 ult=1.0；二转强化线 ×1.2~1.3、新技能线 ×1.15），✅ 提交 8 复核落地（原「一转大招倍率 1.2（示例）」示例作废）。

## 10.7 科技树与难度倍率（v0.11 新增，阶段 4）

**科技树**：全局永久加成，大厅"科技"页签消费。
- 科技点获取（✅ v0.14.1 全链路）：每关首次通关 +2、重复通关 +1，按难度材料倍率缩放（标准 ×1.0 / 困难 ×2.0；v0.31.2 移除轻松）；`BattleSession.pending_tech_points` → 胜利提交写档。
- 三分支实现值（✅ v0.14.1 落地；**v0.26.0 重构为四类 31 项**）：**经济**（初始金币 +20/40/60）、**军事**（全武将伤害 +2%/4%/6%）、**基建**（基地生命 +1/2/3）；建造位解锁费用由 `BuildSlotData.unlock_cost` 按关配置（50~80/个，见 STAGES.md 5.1），不纳入科技加成。
- **四类分类（✅ v0.26.0，阶段 8 提交 3）**：**军略**（全武将伤害 3 项 + 六职业分支各 2 级，职业伤害/攻速/buff 效果 ≤10%）、**后勤**（初始金币 3 项 + 波次奖励 20/40%）、**工事**（基地生命 3 项）、**将略**（积怒/回收率/升阶折扣/军需折扣各 2 级 ≤10%）；`TechPanel` 四页签 + 树状布局（前置链分列、tier 分层、竖线连接）+ 点击详情（v0.30.2）；封顶按 10.7 原则（伤害 ≤15%、职业/机制 ≤10%、波次奖励 ≤40%）。
- **上限原则：全局加成合计不超过 ±15% 强度**——科技树是"刷关价值的兑现"，不是数值通胀的出口；与难度设定（见下）互为对冲。

- **科技重置（✅ v0.26.0 落地，v0.23.0 拍板）**：允许**无条件重置**——免费、不限次数、全额返还科技点（不做 80% 折损）；已解锁科技不丢失、仅迁移到新分类（阶段 8 提交 3 迁移时适用）。

**难度设定（✅ v0.14/v0.14.1；v0.31.2 两档化）**：选关时选择（默认标准；困难需该关标准通关后解锁），结算按难度分键写入 `stage_progress[].difficulties`，后续档位解锁读取上一档通关记录。**档位数据驱动（v0.31.2）**——难度定义收敛到 `BalanceData.difficulty_presets`（`resources/balance/game_balance.tres`：key/name/敌人倍率/奖励倍率/材料倍率），代码经 `Difficulty` 只读引用；**拓展新难度 = 在 `difficulty_presets` 追加一项**（解锁规则自动生效：首档恒解锁、后续档需通关上一档），无需改代码。

| 难度 | 敌人 HP/伤害 | 击杀奖励/经验 | 材料/科技点 |
|---|---|---|---|
| 标准 | ×1.0 | ×1.0 | ×1.0 |
| 困难 | ×1.4 | ×1.6 | ×2.0 |

> v0.31.2：移除轻松（×0.8 无挑战意义），保留标准/困难两档；后续新难度按 difficulty_presets 追加并沿用"通关上一档解锁"规则。

## 10.9 阶段 8 玩法打磨数值草案（v0.20.0 定稿；升阶/军需 ✅ v0.21.0、转盘/波次/连击 ✅ v0.25.0、科技树四类 ✅ v0.26.0 已实施，数值初稿待平衡）

## 10.12 伤害类型与护甲模型（2026-09-09 拍板，✅ 0.8.13.0 已落地）

> 本小节替换此前"护甲 = 线性减算"口径（v0.7）；旧内容保留作历史。敌人甲值见 ENEMIES 5.5.5；完整方案见 `docs/proposals/CH1_COMBAT_RICHNESS_PLAN.md` v0.4。

**伤害类型（来源标签，随 `take_damage` 结算）**：

| 类型 | 对护甲 | 可被减伤 | 来源 |
|---|---|---|---|
| 物理 | 算全部护甲 | 被护甲减免 | 近战/箭/投石普攻、大部分技能/大招 |
| 魔法 | 算 50% 护甲 | 被护甲减免（半额） | 术士类、火攻/灼烧 DoT、术法区域 |
| 真实 | 无视（×0） | **不可被任何减伤** | 青龙偃月、骑兵大招（清单见下） |

**护甲结算公式（替换 v0.7 线性减算）**：

```text
1) 类型系数：armor_eff = max(armor × f_type, 0)
     f_type：物理 1.0 / 魔法 0.5 / 真实 0
2) 百分比穿甲：跨不同来源乘算 Π(1 − pᵢ)；单来源 ≤30%；同武将塔同来源不叠加、取最高
     armor_p = armor_eff × 剩余系数
3) 固定穿透：armor_f = max(armor_p − pen_flat, 0)
4) 减伤：m = armor_f / (armor_f + 50)
     实际伤害 = 基础伤害 × (1 − m)
     真实伤害：跳过 1–4，恒 = 基础伤害
```

- **不设保底**：减伤为比值型，随甲值渐近 <100%、永不归零，故无需 v0.7 的 10% 下限（真实伤害本就满伤）。
- 多来源百分比穿甲**乘算**；单源 ≤30%；同来源多塔取最高不连乘，防重复造塔堆穿甲。固定穿透在百分比之后。
- 护甲不减漏怪伤害（`damage_to_base`）、不影响控制/状态命中、不影响 DoT 结算规则本身（DoT 归魔法，免 50% 甲）。

**真实伤害来源清单（2026-09-09，克制少量）**：关羽·青龙偃月（**3 段 × 2.0× 真实伤害**，溢血转下一目标、每击杀 -5s 冷却，CHARACTER_SKILLS v0.8）；骑兵大招 `ultimate_cavalry_breaker`（3× 单体·斩杀返怒）。其余不设真伤（黄忠·定军山保持物理 + 定军易伤 4s）。**所有伤害描述须标注伤害类型**（物理/魔法/真实），同步技能说明/图鉴/飘字文案。

**实现落点（✅ 0.8.13.0，程序 0.8.12.0 → 0.8.13.0）**：

- **类型常量与显示名**：`scripts/combat/DamageTypes.gd` —— `PHYSICAL`（系数 1.0）/ `MAGIC`（0.5）/ `TRUE`（0.0），显示名「物理 / 魔法 / 真实」；所有伤害描述文案统一经此标注。
- **结算入口**：`Enemy.take_damage(amount, source_character_id, damage_type, pen_ratios, pen_flat)` —— 护甲结算唯一落点；塔 / 弹道 / 技能 / 军需只传类型与穿透参数，不自行抄公式。
- **常数 C**：`BalanceData.armor_constant = 50`（`resources/balance/game_balance.tres`），即 `m = armor_f / (armor_f + C)`。
- **百分比穿甲入参**：`Dictionary {来源 key: 比值}` —— 同源取最高由调用方按 key 聚合（同 key 只保留最强值）、跨源乘算；单源 clamp ≤ 30% 与乘算在 `Enemy` 侧执行；固定穿透 `pen_flat` 在百分比之后扣减。
- **普攻类型来源**：`ProfessionData.attack_damage_type`（术士 = 魔法，其余职业 = 物理）；技能 / 大招 / 灼烧在调用点显式标注（真伤清单见上）。
- **敌人甲值**：第一章全敌显式配置（表见 ENEMIES 5.5.5），不再默认 0 / 继承模板默认。
- **回归**：`tests/BenchmarkRunner.gd` 新增 §4.4 算例逐条断言（无甲 / 甲 10 物理 / 甲 10 魔法 / 甲 20 / 甲 30 / 甲 30 + 双源穿甲 / 同源双塔取最高 / 真实）；基线快照按新公式重算入库。

## 10.16 隐匿与破隐（2026-09-09 定稿，✅ 0.8.13.1 已落地）

> 机制口径与破隐来源见 [BEHAVIORS.md](BEHAVIORS.md) B.3.5；敌人数值见 [ENEMIES.md](ENEMIES.md) 5.5.5；关卡波次见 [STAGES.md](STAGES.md) §7；完整方案见 `docs/proposals/CH1_COMBAT_RICHNESS_PLAN.md` v0.4 §3。

**机制（两轴独立，可与护甲叠加）**：

- 隐匿是**状态**（`EnemyData.stealth` / `Enemy.stealth`）：无目标框、不显示血条（保留虚影与行进提示），**不可被“以单位为目标”的攻击选中**——普攻、单体技能、需选目标的大招与自动大招全部跳过。
- **范围 / 无差别区域效果可命中隐匿**（军需火攻、焚营区域、区域大招、灼烧）：范围克隐匿，破隐负责精确锁定与高效单点。
- 隐匿**不改变**伤害类型与护甲结算（两条轴独立）。

**破隐来源（“可授予 flag”聚合到塔 `Tower.reveals_stealth()`）**：

| 来源 | 载体 | 参数 | 半径 / 时长 |

| 固有破隐 | 黄忠（弓箭手·哨戒） | `trait_params.reveal_stealth = 1.0` | 自身射程 · 常驻 |
| 全图点亮 | 诸葛亮·借东风 | `character_skill_params.reveal_stealth = 1.0` | **全图** · 技能时长 8s |
| 范围光环 | 貂蝉（舞娘）局内 **3 阶**及以上 | 光环按 0.25s 扫描刷新 | 半径 = 舞娘射程（145）· 覆盖期内常驻 |

- 破隐**不做一次性现形**：离开覆盖 / 效果结束即恢复隐匿；点亮期间可锁。
- 军需**不提供**破隐（2026-09-09 拍板，勿扩）；转职“哨戒线”/科技“瞭望”为远期项。
