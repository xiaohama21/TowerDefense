# 游戏百科（ENCYCLOPEDIA）

> 隶属《烽火连营·三国塔防》设计文档体系，总纲见 [../GAME_DESIGN.md](../GAME_DESIGN.md)，界面排版规范见 [UI_LAYOUT.md](UI_LAYOUT.md)，界面职责表见 [UI.md](UI.md)。
> 文档版本：v0.1（2026-09-01，用户拍板定稿）
> 应用阶段：**阶段 8·提交 9（游戏百科，原提交 5）**，未开发。
> 范围：武将图鉴（全量信息 + 数值模拟器）与敌人图鉴（三档难度面板 + 出现关卡）；后续"发现解锁"与阶段 10 渐进解锁一并实施。

---

## 1. 功能定位

- 百科是**只读信息中心**：展示武将、敌人的完整信息与数值预览，不提供任何写档操作。
- 入口：游戏大厅侧栏新增"百科"按钮（UI_LAYOUT.md 已预留侧栏扩展位）；内部**武将 / 敌人**两个页签。
- 与养成面板的职责划分：**百科=完整图鉴 + 数值预览**；养成面板保持现状（仅对已拥有武将提供转职/信物等操作；升星随 v0.30.0 暂时移除）。两者不重复承担图鉴职责。

## 2. 武将图鉴

### 2.1 信息展示

- 左侧武将列表：网格卡片（头像占位 / 姓名 / 职业 / 定位标签），全部 9 名武将可浏览。
- 右侧详情（页签结构，符合 UI_LAYOUT.md 信息分层）：
  - 「基础」：等级 + 经验条、职业、属性摘要（伤害 / 攻速 / 射程，蓝色数值）、获取方式。
  - 「转职」：一转/二转路线、各档技能说明、转职倍率。
  - 「升星」：星级、碎片用途、成长系数（升星系统 v0.30.0 暂时移除，百科同步移除该页签，恢复时按本设计接入）。
  - 「信物」：信物效果与获取方式。
  - 「特性」：角色常驻特性说明（阶段 9 升阶特性接入时同步展示，不改布局）。

### 2.2 数值模拟器（预览，不写档）

- 界面内可调整：**局外等级**（1~30，上限随总纲后续章节放开）、**转职**（当前路线任选，**不校验等级/材料条件**）、**局内升阶**（0~3 阶；阶段 9 开放 5 阶后自动跟随）、**星级**（可选，0~当前上限）。
- 属性实时重算并展示（伤害 / 攻速 / 射程 / AOE 半径 / buff 时长与效果等，随职业显示对应侧重项）。
- **实现**：复用 `CharacterData.compute_stats_at()` 并新增 `battle_rank` 参数（升阶数值读取 `ProfessionData.battle_rank_*` 与 `CharacterData.battle_rank_*_override`），**与战斗内数值同源**，禁止另写一套算法。
- **边界**：模拟器为只读假设视图，**不写存档、不记录转职路径**；界面固定标注"预览不影响存档"；转职预览不校验材料/等级，但显示"如已满足条件"的提示文字。

### 2.3 解锁规则（当前版全量，后续随阶段 10）

- 当前版：**全部武将信息可见**（含未拥有武将）。
- 后续（阶段 10 渐进解锁实施时同步）：按**发现解锁**——未拥有/未发现武将仅显示轮廓与获取方式，已发现显示完整信息；发现记录新增存档字段（提交 9 不开发、不新增字段）。

## 3. 敌人图鉴

### 3.1 信息展示

- 敌人列表：网格卡片（造型色块 / 名称 / 定位 / 阵营标签），第一章全部敌人（步卒 / 轻骑 / 伍长 / 弓手 / 力士 / 祭酒 / 渠帅·张梁）。
- 详情：
  - 基础面板：生命 / 速度 / 护甲 / 漏怪伤害 / 特殊行为（名称 + 说明）。
  - **三档难度面板**：轻松 / 标准 / 困难，数值 = 基础属性 × `Difficulty.enemy_hp_mult()`（HP/伤害随难度）；**速度 / 护甲不随难度变化**，面板注明。
  - **出现关卡**：反查 `StageData.waves → EnemySpawnData.enemy_id`，列出该敌人出现的全部关卡（含 Boss 召唤物来源说明）。

### 3.2 解锁规则（当前版全量，后续随阶段 10）

- 当前版：全部敌人信息可见（含未遭遇敌人）。
- 后续（阶段 10 渐进解锁实施时同步）：**难度面板解锁**=任意出现该敌人的关卡已解锁该难度（沿用 `GameFlow.is_difficulty_unlocked()`）；**关卡信息解锁**=对应关卡已解锁（沿用前置通关进度）；未解锁部分灰显。

## 4. 数据与实现约束

- 武将数值预览：`compute_stats_at(level, promotion, stars, relic, battle_rank)`（新增参数，默认 0 不影响现有调用）。
- 敌人难度面板：复用 `Difficulty.enemy_hp_mult()`，不新增倍率表。
- 出现关卡反查：使用 `GameFlow.load_stage_data()` + 资源目录扫描（PCK 兼容已验证 v0.19.6），启动时构建一次 `enemy_id → stage_ids` 索引。
- 提交 9 **不新增存档字段**；发现/难度解锁记录字段随阶段 10 一并设计。
- UI 遵循 UI_LAYOUT.md：网格布局、语义色板（金色=关键资源/预览值、绿色=已解锁/可看、红色=未解锁/不可看）、关键信息高亮、按钮四态。

## 5. 验收标准（阶段 8·提交 9）

- 侧栏"百科"入口可用，武将/敌人页签切换正常。
- 武将图鉴：9 名武将全量信息可浏览；模拟器调整等级/转职/升阶/星级后属性实时变化，且与战斗内同配置抽样数值一致（自动化断言）。
- 敌人图鉴：全部敌人三档难度面板正确（HP/伤害随倍率、速度/护甲不变并注明）；出现关卡反查与关卡配置一致。
- 模拟器操作不产生任何存档变化（断言存档哈希不变）。
- 流程测试与冒烟测试全绿。

## 6. 不做什么

- 不做"发现解锁"本体（随阶段 10 渐进解锁实施）。
- 不做写档/预览转职记录。
- 不做敌人图鉴的战斗内查看入口（仅大厅百科）。
- 不做正式美术素材（立绘/图标沿用程序化占位）。
