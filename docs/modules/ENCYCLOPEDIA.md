## 1. 功能定位

- 百科是**只读信息中心**：展示武将、敌人的完整信息与数值预览，不提供任何写档操作。
- 入口：游戏大厅侧栏新增"百科"按钮（UI_LAYOUT.md 已预留侧栏扩展位）；内部**武将 / 敌人**两个页签。
- 与养成面板的职责划分：**百科=完整图鉴 + 数值预览**；养成面板保持现状（仅对已拥有武将提供转职/信物等操作；升星随 v0.30.0 暂时移除）。两者不重复承担图鉴职责。

## 2. 武将图鉴

### 2.1 信息展示

- 左侧武将列表：网格卡片（姓名 / 职业名·战斗定位词，卡片按宽度精简、不省略号硬塞；攻击方式 / 克制等长信息在右侧详情「基础」页），全部 9 名武将可浏览。
- 右侧详情（页签结构，符合 UI_LAYOUT.md 信息分层）：
  - 「基础」：等级上限（1~30，读 `BalanceData.max_level`，勿硬编码）+ 经验条说明、职业（含职业定位与克制标签）、属性摘要（伤害 / 攻速 / 射程，蓝色数值）、角色简介（`CharacterData.description`）、**获取方式**（复用 `GameFlow.get_acquisition_text`：`unlock_stage_id` 空 =「初始解锁」（刘备/关羽，B-022 修复后）；非空 =「通关「关卡名」首通解锁」；关卡缺失 =「随章节更新解锁」）。
  - 「技能」：**角色专属技能**（A 主动冷却 / B 条件被动，名称 + 效果 + 数值，见 [CHARACTER_SKILLS.md](CHARACTER_SKILLS.md)）与**职业大招**（按角色职业展示大招名、效果与怒气说明；角色级大招覆盖预留位为空时读职业默认）；与职业技能档位无关，不参与档位显示。
  - 「转职」：职业级转职树（该角色职业的一转/二转路线，同职业角色共享）、各档职业技能说明（档位系数仅职业技能适用、以局内升阶 `battle_rank` 为准，见 SKILLS.md 第 5 节）、转职倍率（伤害/射程/攻速/大招，读 `PromotionData`）。
  - 「信物」：信物效果与获取方式（绑定武将，`GameFlow.get_relic_for_character` 反查）。
  - 「特性」：角色常驻特性说明（`CharacterData.trait_id` + `trait_params`，9 名武将数据齐全——B-022 补齐赵云/周仓/诸葛亮；阶段 9 升阶特性接入时同步展示，不改布局）。
  - 「升星」：星级、碎片用途、成长系数——**升星系统 v0.30.0 暂时移除，百科同步不展示该页签**；恢复时按 v0.1.1 前设计接入。
- 页签扩展原则：未来新增角色信息（如特性分支、三转）只增页签，不改既有布局（UI_LAYOUT.md 通用原则）。

### 2.2 数值模拟器（预览，不写档）

- 界面内可调整：**局外等级**（1~30，上限随总纲后续章节放开）、**转职**（当前路线任选，**不校验等级/材料条件**）、**局内升阶**（0~3 阶；阶段 9 开放 5 阶后自动跟随）。**星级不可调**（升星 v0.30.0 暂时移除，星级模拟一并移除）。
- 属性实时重算并展示（伤害 / 攻速 / 射程 / AOE 半径 / buff 时长与效果等，随职业显示对应侧重项；展示项与战斗内已建塔属性面板对齐）。
- **实现**：复用 `CharacterData.compute_stats_at()` 并新增 `battle_rank` 参数（读 `ProfessionData.battle_rank_*` 与 `CharacterData.battle_rank_*_override`）；**升阶乘区（伤害/攻速/射程/AOE/buff 时长与强度）与 `Tower.apply_battle_rank` / `get_battle_rank_*` 公式共享实现（抽公共函数或复用同一倍率来源），禁止另写一套算法**；特性静态加成（如诸葛亮观星射程 +12%）同样纳入预览计算。
- **边界**：模拟器为只读假设视图，**不写存档、不记录转职路径**；界面固定标注"预览不影响存档"；转职预览不校验材料/等级，但显示"如已满足条件"的提示文字。

### 2.3 解锁规则（当前版全量，后续随阶段 10）

- 当前版：**全部武将信息可见**（含未拥有武将）。
- 后续（阶段 10 渐进解锁实施时同步）：按**发现解锁**——未拥有/未发现武将仅显示轮廓与获取方式，已发现显示完整信息；发现记录新增存档字段（提交 9 不开发、不新增字段）。

## 3. 敌人图鉴

### 3.1 信息展示

- 敌人列表：视图顶部为**章节选择行**（第一章可点、后续章节灰显「敬请期待」，与地图选关共用 MapPanel.RESERVED_CHAPTERS 单源清单）；列表 = 当前章节敌人 **2 列网格卡片**（名称 / 定位·阵营），第一章全部敌人（步卒 / 轻骑 / 伍长 / 弓手 / 力士 / 祭酒 / 渠帅·张梁，与 ENEMIES.md 5.5.2 一致）。当前仅第一章有敌人目录，后续章节敌人随章节数据落地后按章节筛选；武将图鉴不分章节（跨章节角色池）。
- 详情：
  - 基础面板：生命 / 速度 / 护甲 / 漏怪伤害 / 特殊行为（名称 + 说明，玩家向文案字典集中维护，勿直出 `special_behavior_id`）。
  - **各档难度面板**（当前 2 档=标准/困难，v0.31.2 移除轻松；后续随 `difficulty_presets` 档位数自动扩展）：**HP 随难度** = 基础 `max_hp` × `Difficulty.enemy_hp_mult()`（标准 ×1.0 / 困难 ×1.4）；**漏怪伤害 / 速度 / 护甲不随难度变化**，面板注明（BalanceData 仅 `enemy_hp_mult` 一个敌人倍率，v0.33.7 口径收口）。
  - **出现关卡**：反查 `StageData.waves → EnemySpawnData.enemy_id`，列出该敌人出现的全部关卡（含 Boss 召唤物来源说明，如 s08 张梁召唤步卒）。

### 3.2 解锁规则（当前版全量，后续随阶段 10）

- 当前版：全部敌人信息可见（含未遭遇敌人）。
- 后续（阶段 10 渐进解锁实施时同步）：**难度面板解锁**=任意出现该敌人的关卡已解锁该难度（沿用 `GameFlow.is_difficulty_unlocked()`）；**关卡信息解锁**=对应关卡已解锁（沿用前置通关进度）；未解锁部分灰显。

## 4. 数据与实现约束

- 武将数值预览：`compute_stats_at(level, promotion, stars, relic, battle_rank)`（新增 `battle_rank`，默认 0 不影响现有调用；`stars` 参数保留、恒 0——升星 v0.30.0 暂时移除，恢复时启用）。
- 敌人难度面板：仅复用 `Difficulty.enemy_hp_mult()`，不新增倍率表；漏怪伤害/速度/护甲按基础值展示并注明不随难度。
- 出现关卡反查：使用 `GameFlow.load_stage_data()` + 资源目录扫描（PCK 兼容已验证 v0.19.6），启动时构建一次 `enemy_id → stage_ids` 索引。
- 文案字典（特性 / 职业技能 / 角色技能 / 敌人特殊行为 / 获取方式）集中维护或复用既有字典（如 `DevelopPanel` trait 文案表），禁止各面板散落私有文案导致漂移。
- 提交 9 **不新增存档字段**；发现/难度解锁记录字段随阶段 10 一并设计。
- UI 遵循 UI_LAYOUT.md：网格布局、语义色板（金色=关键资源/预览值、绿色=已解锁/可看、红色=未解锁/不可看）、关键信息高亮、按钮四态；按 v0.33.4~v0.33.6 定稿的 Kenney 亮蓝 + 站酷快乐体视觉规范实现（UITheme）。

## 5. 验收标准（阶段 8·提交 9）

- 侧栏"百科"入口可用，武将/敌人页签切换正常。
- 武将图鉴：9 名武将全量信息可浏览（含技能页签与获取方式，初始武将显示「初始解锁」）；模拟器调整等级/转职/升阶后属性实时变化，且与战斗内同配置抽样数值一致（含观星等特性静态加成，自动化断言）；模拟器操作不产生任何存档变化（断言存档哈希不变）。
- 敌人图鉴：全部敌人各档难度面板正确（当前 2 档=标准/困难，HP 随倍率、漏怪伤害/速度/护甲不变并注明）；出现关卡反查与关卡配置一致。
- 流程测试与冒烟测试全绿。

## 6. 不做什么

- 不做"发现解锁"本体（随阶段 10 渐进解锁实施）。
- 不做写档/预览转职记录。
- 不做敌人图鉴的战斗内查看入口（仅大厅百科）。
- 不做正式美术素材（立绘/图标沿用程序化占位，按 v0.33.x 视觉规范呈现）。
