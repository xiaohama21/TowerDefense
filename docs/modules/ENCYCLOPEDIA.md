## 1. 功能定位

- 百科是**只读信息中心**：展示武将、敌人的完整信息与数值预览，不提供任何写档操作。
- 入口：游戏大厅侧栏新增"百科"按钮（UI_LAYOUT.md 已预留侧栏扩展位）；内部**武将 / 敌人**两个页签。
- 与养成面板的职责划分：**百科=完整图鉴 + 数值预览**；养成面板保持现状（仅对已拥有武将提供转职/信物等操作；升星随 v0.30.0 暂时移除）。两者不重复承担图鉴职责。

## 4. 数据与实现约束

- 武将数值预览：`compute_stats_at(level, promotion, stars, relic, battle_rank)`（`battle_rank` 默认 0 不影响现有调用；`stars` 恒 0——升星 v0.30.0 暂时移除）；射程预览乘 `CharacterData.get_static_range_multiplier()`。
- 列表顺序字典：武将 `CHARACTER_ORDER`（概念顺序，目录新增回退补齐）；敌人 `ENEMY_ORDER`（ENEMIES.md 5.5.2 表序，缺失项跳过）。武将头像配色键 = `CHARACTER_AVATAR_COLORS`（九色，缺失回退蓝），不随职业色。
- 文案字典（集中维护、禁止面板间漂移）：卡片副行 = 职业名 · 打法词（`CHARACTER_FLAVOR`）/ 敌人定位词 · 打法词（`ENEMY_LOCATIONS` / `ENEMY_TACTIC_SUB`）；头部 chips 职业定位短词与养成页签同源 `DevelopPanel.PROFESSION_TAG_LABELS`；技能 / 大招 / 特殊行为 / 获取方式沿用既有字典与 `GameFlow.get_acquisition_text`。
- 敌人难度面板：仅复用 `Difficulty.enemy_hp_mult()`，不新增倍率表；速度/护甲/漏怪伤害按基准值展示并注明不随难度。
- 出现关卡反查：使用 `GameFlow.load_stage_data()` + 资源目录扫描，启动构建一次 `enemy_id → stage_ids` 索引；头部摘要去重取直出或首个来源，多关按关号升序。
- UI 遵循 UI_LAYOUT.md：Kenney 亮蓝 + 站酷快乐体（UITheme 共享组件）；头部虚线分隔 / 敌人方形渐变头像为自绘（StyleBox 不支持 dashed / 渐变头像）小部件，色值见实现常量注释；EnemyAvatar 渐变纹理 setup 预生成 ImageTexture 缓存绘制（B-048 纹理上传时序，禁止在 _draw 内现建纹理）。
- 提交 9 / 本次延伸**不新增存档字段**；发现/难度解锁记录字段随阶段 10 一并设计。
