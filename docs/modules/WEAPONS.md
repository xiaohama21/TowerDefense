## 1. 槽位、库存与获取

每将一个武器槽，仅限已拥有且职业适配的装备，免费换装、卸下。一件只供一将使用，同款数量包含装备中的件数，未占用数=持有数−装备数。第一章仅凡品12款，每款2条固定词条，无随机、打造、图纸、升级、精炼或特效。品质沿用ItemData.Rarity五档，与武将六阶分开。

对应关全局首通，每款必得1件；重复通关每款独立30%补1件（标准、困难共用首通记录）。上限3件，超额每件转将印2；装备及其折算均不吃材料难度倍率。奖励只进BattleSession.pending_weapons，胜利保存成功才写入档案，失败、退出、重复提交不授予。保存失败不改变库存、装配、将印或关卡记录。

首通后常驻商店120元宝/件、满3禁购的设计保留；0.9.3仅提供价格和解锁关元数据，购买与元宝、主公、商店容器统一在0.9.4/schema v10接入。

## 3. 数值来源

固定攻击并入基础值，与等级、品阶、信物虚拟等级、局内升阶同倍增长；裸成长保障不吞掉装备加值。暴击率、爆伤、技能增幅同层加法，暴击率沿用75%封顶。永久被动与动态技能共用装备增幅，技能等级倍率独立相乘。固定射程先加、装备射程百分比与观星百分比同层相加，再乘局内范围倍率。溅射固定值先加，再乘装备范围百分比和局内范围倍率；弹道固定值先加。

伤害类型百分比只对该类型进入L1，与信物同层加法，不修改普攻攻击面板。武器穿甲独立来源，单源≤30%、与技能来源跨源乘算、固定穿透在后，武器穿甲不吃技能增幅。怒气获取与科技百分比相加再乘月华；骨朵只在真实普攻命中时额外+1（AOE每发一次），之后按常规怒气倍率，不影响辅助脉冲、固定返怒。固定DoT保持不吃魔法伤害、穿甲、暴击与技能增幅。

## 4. schema v9与界面

v8→v9补weapons={}及characters[id].weapon_id=""；无首通补发。未知ID、非法数量、职业不匹配与超配装归一，按角色ID排序保留合法装配，迁移幂等且保留经验、品阶、技能与保障。换装采用副本保存成功后替换live档案。

养成页签技能／品阶／装备／信物。装备卡共用图徽、职业、独立装备品质徽记、持有及可用数量、两行词条与动作；名字和获取规则放tooltip。百科可浏览适用双款、在模拟器切换并重算，与战斗共用compute_stats_at，预览不写档。背包分类加入装备，显示库存、占用与词条。地图首通预告、结算均显示装备图徽＋数量，溢出显示折算将印。五档品质图徽于0.9.4.2补齐，登记ART_PROMPTS与src/README；当前凡品直接显示菱形徽记。
