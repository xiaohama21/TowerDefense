## 1. 场景与入口

沿用GameHub场景路径作为主城，替换左侧导航大厅。开始/继续游戏、战斗结算返回均进入主城全景；城门进入现有选关，编队返回仍定位到选关。功能页在主城上方打开，返回/ESC关闭回城；系统菜单放右上角，设置、返回主菜单、退出均可达。退出经确认。

固定九座建筑，原创SVG营地插画表现建筑用途，入口牌常显定稿建筑名称，辅以动作或状态；简短用途放悬停/键盘焦点详情。锁定建筑仍可查看开放条件。酒馆与兽栏保留建筑轮廓、材质并显示“未开放”，不能进入虚假功能。原有军需在中军帐内保留管理入口，至0.10.3再整体删除。各页延用已交付内容，不新增主城战力、建筑等级、坐骑或招募。

| 建筑 / 路由 | 内容 | 新档开放条件 |
|---|---|---|
| 城门 / map | 选关→编队→战斗 | 初始 |
| 中军帐 / command | 主公等级、经验、通关进度、军需管理 | 初始；军需入口在s04通关后开放 |
| 演武场 / develop | 武将等级、品阶、技能、装备与天赋 | s01通关 |
| 军机帐 / tech | 科技树 | s05通关；已有科技点或科技时提前保留入口 |
| 酒馆 / tavern | 施工预留 | 0.10.2开发 |
| 兽栏 / stable | 施工预留 | 0.10.4开发 |
| 市集 / shop | 元宝 / 军功双商店 | s02通关；已有装备时提前保留入口 |
| 库房 / inventory | 背包、装备、信物与遗物 | s01通关；已有库存时提前保留入口 |

渐进解锁只限制入口，不限制已拥有物品、武将和已生效科技在战斗中的使用。已花费经验池、升级/进阶武将或已有装备/技能/天赋的档案保留养成入口；已有军需强化/选带保留军需管理。规则集中于CityRegistry与独立.tres配置，UI与首用记账使用同一判定，锁定入口不能绕过。

## 2. 首用与状态

可用但未访问的入口显示红点；首次打开时显示可跳过的一句说明。关闭或跳过才原子保存“已访问”，保存失败保留红点并允许重试，不修改资源或成长。不在刚进主城时连弹多个窗口。施工建筑没有红点。当前没有建筑升级系统，不显示无效升级按钮。

## 3. 存档与兼容

schema12→13新增city_state，仅包含legacy_access（bool）与visited（有效入口ID列表）。迁移旧档时legacy_access=true，保证所有已实装入口继续可用；新档false按进度开放。未知/重复访问ID清理，施工ID不记账。迁移不补发经验、货币或角色，不清除军需；schema13重读幂等，高版本保护沿用原事务路径。

## 4. 视觉

当前采用暖日照青绿营地（0.10.1.2，详见§7），布局沿九建筑入口，主体结构各自设计；锁定态保留正常素材亮度，以浅色入口牌与明确状态区分。2026-11-09昼/暮候选及暮色选择仅作历史存档，本次用户反馈已更新视觉方向。建筑可点击轮廓与图像对应，城门显著；道路连接各功能区，顶部为主公/元宝/军功图徽与数值，右上为系统菜单。常显完整建筑名及小动作行，用途通过悬停及键盘焦点说明；资源不重复写名词。1280×720基准，缩放与宽屏按比例居中，功能页保留原内容宽度，长列表内部滚动。

## 6. 美术升级（0.10.1.1历史记录）

以下记录上一版实施与验收；暮色、仅动作入口牌及旧功能页皮肤均已由§7的0.10.1.2当前口径替代。

针对用户反馈的主城过于简陋，沿已选定的暮色墨绿暖金升级。左上暖光、右侧阴影统一；建筑必须看见正面与侧面、檐口厚度、瓦片层次、木梁与窗格，帐篷以布褶/撑杆/旗帜表达体积。九建筑以城门、主帐、练兵靶场、沙盘帐、酒肆、兽栏、市集货摊、粮库和书楼的实物陈设区别用途。各入口仍在200×199点击区域内，200×175图像与底部动作不交叠，不以增加按钮名称补足辨识。

背景采用远山、松林、营垒、坡面与前景遮挡的分层构图；道路以土石材质、路肩与浅车辙连接原有入口。草丛/碎石低对比且疏密变化，火把/灯笼暖光辅助方向，不遮建筑与HUD。素材保留透明边界，SVG只使用Godot可渲染的路径、渐变和图案，不依赖滤镜。逻辑尺寸保持，纹理以2倍清晰度导入。

锁定入口的建筑保留可辨认的材质与结构，常显“查看条件”或“未开放”，不再用全画面大虚线圆压住建筑。可进入入口显示动作底牌；悬停/键盘焦点用地面金色轮廓、底牌和轻微亮度提示。首用红点及保存行为保持。顶部三组图徽＋数值、系统菜单与底部说明统一深墨/暖金材质，覆盖功能页的现有样式保持。

验收以Godot原生新档、全部解锁、悬停/键盘焦点、施工、菜单、首用、实际功能页及1600×900画面为准；与0.10.1.0并排对照，检查边界/热区/文字和图像裁切。运行City/Flow/ExitFlow/PackVerify相关回归，检查两套色板SVG和Windows独立包、PE版本及Spine DLL。历史连续通关证据保留，战斗资源逐文件核对。

0.10.1.1已验收：四项相关回归、156项主城、16张原生图、587项Windows包检查通过，导出运行输入哈希一致；[报告](../reviews/CITY_ART_2026-11-17.md) / [前后对照](../ui_concept/runtime_0.10.1.1/before_after.png)。

## 7. 明亮营地与全界面协调（0.10.1.2）

本次用户反馈优先于先前暮色方案：默认为暖日照青绿营地，降低暗角与地面遮罩；锁定保持正常素材亮度，以浅牌、状态字和边框区别。原昼/暮概念保留历史，新的两套素材单独归档。玩家入口采用定稿名称（第1节表），不得把动作当作建筑名；牌上建筑名18px、动作/条件12px，保持200×199热区。兽栏画圈养场，不画马厩。

| 建筑 | 主体辨识特征 |
|---|---|
| 城门 | 双门楼、厚城墙与大门洞 |
| 中军帐 | 宽大双尖主帐、军旗与中央入口 |
| 演武场 | 露天靶场、兵器架、地面练兵圈 |
| 军机帐 | 低矮开放单坡帐棚、前景大沙盘 |
| 酒馆 | 窄高两层酒肆、红瓦酒幌与酒坛 |
| 兽栏 | 开放围栏、动物轮廓与侧棚 |
| 市集 | 多个彩布货摊与成排货品，没有整座居室 |

功能覆盖层采用暖纸面、细木金边、青绿选中态，与主城入口牌同源；顶部显示建筑图像＋名称以定位当前位置，右上返回及ESC行为保持。全部动作/选择/圆形按钮采用同一材质并保留hover、pressed、hover_pressed、disabled、focus；新增原生全界面截图与包检查。全局规范见UI_LAYOUT末节。
