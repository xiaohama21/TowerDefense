## 5.1 关卡结构

关卡由 `StageData` 定义：`starting_lives`（基地生命）、`starting_currency`（初始金币）、`squad_size`（可出战武将数）、`build_slot_count`（建造槽）、`waves`（波次列表）、`prerequisite_stage_ids`（前置关卡）、局内升级与回收参数（`max_inbattle_upgrade_level` / `upgrade_cost_factor` / `sell_refund_ratio`，见 5.4，v0.9 已实施）。

**布局字段（v0.9 数据驱动化，`StageData` 新增）**：`path_points`（直角折线拐点，含图外出入口延长段）、`build_slot_positions`（建造位坐标）、`decor_cells`（装饰格）。道路格子由 `path_points` 逐格推导（`GridBackground.derive_road_cells`），出入口地标取首/末图内格；建造位、道路、地标均不再硬编码于场景。

- **胜利条件**：全部波次清空且基地生命 > 0。
- **失败条件**：基地生命归零。
- **波次**（`WaveData`）：由多个出生组（`EnemySpawnData`：敌人类型+数量+间隔）构成；`preparation_time` 为波前准备期（v0.7 明确：当前版本采用**手动开波**，玩家点击开始按钮放行，该字段保留给【远期】"准备期倒计时自动开波"模式）；`completion_currency` 为波次完成奖励（默认 0 不启用，见 [NUMBERS.md](NUMBERS.md) 5.3）；`is_boss_wave` 标记 Boss 波。

## 5.2 波次设计规范（模板）

每关建议 5~8 波，节奏遵循模板：

| 波次位置 | 内容 | 目的 |
|---|---|---|
| 第 1 波 | 纯基础兵，数量少 | 教学/热身 |
| 第 2~3 波 | 基础兵+轻骑混编 | 引入新敌人 |
| 第 4 波 | 精英（伍长）+混编 | 压力测试 |
| 第 5 波 | 快慢搭配（轻骑先、步卒后） | 漏怪考验 |
| 第 6~7 波 | 新敌人机制（弓手/祭酒） | 机制教学 |
| 末波（Boss） | Boss + 护卫 | 综合验收 |

## 5.4 局内升级与回收

战斗内对已建塔的两项金币操作，均为**局内临时状态**（与 4.4 的局外等级完全独立，不写入存档）。

- **局内升级**：
  - 每座塔的局内等级（battle_level）从 0 开始，每关最多升至 `max_inbattle_upgrade_level`（初稿 2）。
  - 第 n 次升级费用 = `build_cost × upgrade_cost_factor × n`（初稿 factor=0.8；例：关羽 70 → 第一次 56、第二次 112）。
  - 每次升级效果：伤害 +25%；攻速、射程、特性不变；大招强度随普攻自然提升（倍率定义见 [NUMBERS.md](NUMBERS.md) 10.5）；怒气获取规则不变。
  - 升级入口位于已建塔交互面板，准备期与波次中均可操作。
- **回收（卖塔）**：
  - 回收返还 = 该塔总投入（建造 + 已花费升级）× `sell_refund_ratio`（初稿 0.6），向上取整。
  - 回收后建造槽立即可复用；该塔局内等级与怒气丢弃。
  - 准备期与波次中均可回收。
- **数据层扩展（v0.9 已实施）**：`StageData` 新增 `max_inbattle_upgrade_level: int`、`upgrade_cost_factor: float`、`sell_refund_ratio: float`；战斗内通过已建塔交互面板操作，`TowerManager.upgrade_tower/sell_tower` 执行；数值均为初稿，平衡调整须同步更新本文档与 [NUMBERS.md](NUMBERS.md) 10.3。

## 5.6 关卡布局设计规范（v0.7 新增，数值为初稿）

地图为 16×9 的 80px 网格，路径为直角折线，建造位对齐网格并贴邻道路。短射程职业（骑兵、枪兵）的价值高度依赖"贴路、转角位"的分布，为保证职业差异化成立，新建关卡（`ch01_s02` 起）须遵循：

- **路径**：入口与基地分居地图两端；路径总长度（按格数）初稿 ≥ 24 格；至少 2 个直角转角——转角贴路位是近战/短射程职业的优位。
- **建造位档位**：
  - **贴路位**：与道路格正相邻——骑兵、枪兵等短射程职业的优位；
  - **中程位**：距道路 1 格——术士等中射程职业；
  - **远程位**：距道路 2 格以上——弓箭手等长射程职业的覆盖位。
- **配比下限（每关）**：贴路转角位 ≥ 2、贴路直道位 ≥ 2、中/远程位 ≥ 3；建造位总数 = `build_slot_count`，应比预期成塔数（6~9）多留 2~3 个空位供规划取舍。
- **避免**：整关没有转角（近战职业无优位）、大段无建造位的"真空长廊"（远程也够不着）、路径过度回折导致贴路位过密。
- **联调基准**：每关布局与波次联调时，以"建造位全空、仅初始金币"开局试打，第 1~2 波可存活为下限；末波靠满配阵容可守为上限。
