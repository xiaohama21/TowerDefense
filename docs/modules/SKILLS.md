## 1. 定位与原则

- **技能 = 转职授予的被动/条件触发能力**：由 `SkillRegistry`（`scripts/combat/SkillRegistry.gd`）按 `skill_id` 分发；战斗脚本只调用钩子（`on_attack_hit` / `on_kill` / `on_ultimate_cast` / 被动倍率），不写死任何技能逻辑。数值经 `PromotionData.skill_params` 读取。
- **技能归属职业而非角色**：每个职业拥有"职业技能池"，转职从职业池授予技能；角色只是技能的**当前授予载体**，不构成技能身份。新增角色/转职优先复用职业池，避免"一人一技能"的分散设计。
- **三层边界（可叠加，各有强度预算）**：特性=角色身份被动；大招=职业怒气主动；技能=转职成长被动。普攻/技能/大招分强度预算（NUMBERS.md 10.x），禁止所有效果共用无限乘区。
- **档位系数**：`s = 1 + 0.1 × min(档/5, 4)`（每 5 档 +10%、上限 4 档 +40%）；档位口径见第 5 节。

## 3. 职业技能明细

### 3.1 骑兵（cavalry）

- **职业定位**：短射程、高单体伤害，道路转角压制精英；大招 `ultimate_cavalry_breaker` = 3×普攻单体斩杀、击杀返还 50% 怒气（职业基础）。
- `charge` 蓄力：大招击杀 → 返还怒气 50%×s（与职业大招"击杀返怒"同源，形成大招连发循环）；参数 `base_refund`（基准 50）；演出=大招名飘字。
- `dragon_rush` 龙突：击杀 → 下一次攻击伤害 +25%×s（单体追击链，击杀滚雪球）；参数 `next_hit_bonus`（基准 0.25）；演出="龙突"飘字+扩散环+音效。

### 3.2 剑客（pikeman）

- **职业定位**：便宜、稳定、手长的近战基础职业，对骑兵有克制；大招 `ultimate_pikeman_sweep` = 范围内 1.5×普攻伤害 + 击退 40px。
- `ferocity` 凶威：攻击命中 → 15% 概率追加 0.5×s 普攻伤害（近战连打爆发）；参数 `chance` 0.15 / `mult` 0.5；演出="凶威"飘字+扩散环+音效。
- `command` 统军令：常驻光环 → 周围 150px 友方伤害 +4%×s（自身不吃，前排核心光环）；参数 `radius` 150 / `ally_damage_bonus` 0.04；演出=光环（无飘字）。
- `bulwark` 斩获：击杀 → 额外金币 +2×s（经济回收，呼应每关经济预算的"技能额外金币"项）；参数 `gold` 2；演出="斩获"飘字+音效。

### 3.3 弓箭手（archer）

- **职业定位**：长射程、稳定输出，覆盖道路前后两端；大招 `ultimate_archer_volley` = 4 箭连射（0.8×普攻），优先低血量。
- `steady` 稳射：攻击命中 → 20% 概率追加 0.6×s 普攻伤害（稳定点杀）；参数 `chance` 0.2 / `mult` 0.6；演出="稳射"飘字+扩散环+音效。

### 3.4 术士（strategist）

- **职业定位**：范围法术 + 减速控制敌群，弥补物理输出空窗；大招 `ultimate_strategist_blaze` = 目标区域 2×普攻范围伤害 + 减速 40%/2s。
- `wisdom` 奇谋：大招释放 → 大招范围 +10%×s（法术覆盖放大，与大招协同）；参数 `aoe_radius_bonus` 0.1；演出="奇谋"飘字。

### 3.5 舞娘（dancer）

- **职业定位**：鼓舞邻近人物攻速，直接伤害较低（辅助）；大招 `ultimate_dancer_encourage` = 全队攻速 +30%、伤害 +15%，持续 8s。
- `inspire` 鼓舞：大招释放 → 全队攻速 +6%×s，持续 8 秒（辅助职业"主动双 buff"节奏）；参数 `team_speed_bonus` 0.06 / `duration` 8；演出="鼓舞"飘字。

### 3.6 投石车（catapult）

- **职业定位**：远距离范围压制，攻速极慢、近距离无法攻击；大招 `ultimate_catapult_barrage` = 3 连发快速抛射（0.8×普攻/发）。
- `siege` 攻城锤：常驻 → 对精英/Boss 伤害 +10%×s（攻坚定位，与投石车"压制精英"场景一致）；参数 `elite_damage_bonus` 0.1；演出=无。

## 5. 口径与待办

- **档位口径（待统一）**：设计意图为"技能强度绑定武将等级、每 5 级一档"（CHARACTERS.md 4.5）；`SkillRegistry.tier_multiplier()` 目前按 `tower.battle_rank`（局内升阶阶数）计算，而第一章升阶上限 3 阶 < 5，实际档位恒为 0、`s` 恒为 1——档位系统当前在战斗中不生效。待确认按"角色等级"实现后，统一文档与代码表述。
- **职业化改造（待定，不阻塞现状）**：① 职业技能池正式化——本表为职业池基准，新增技能先登记职业池再挂转职；② 同职业多技能（剑客/骑兵）后续可演化为"一转从职业池选取其一"或"同职业共享池、角色按定位取一"；③ 二转 = 职业池内技能进化（charge 70% 已为先例），不跨职业新增技能。
