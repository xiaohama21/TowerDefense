> 应用阶段：**v0.2 = 职业技能收敛定稿（v0.25.3）**——每职业 1 个职业技能、转职强化（+ / ++）；数值全部待实测；**数据与实现待同步**（现运行版本仍为 v0.1 的 9 技能配置）。

## 1. 定位与原则

- **技能 = 转职授予的被动/条件触发能力**：由 `SkillRegistry`（`scripts/combat/SkillRegistry.gd`）按 `skill_id` 分发；战斗脚本只调用钩子（`on_attack_hit` / `on_kill` / `on_ultimate_cast` / 被动倍率），不写死任何技能逻辑。数值经 `PromotionData.skill_params` 读取。
- **职业技能归属职业且每职业仅一个**：6 个职业各对应 1 个职业技能，代表**职业身份**；角色只是技能的当前授予载体。新增转职/角色优先复用职业技能，不另造技能。
- **转职 = 技能强化（+ / ++）**：一转授予职业基础技能；二转授予同名强化技能（显示名加 `+`），数值提升或按转职定位新增次级机制；三转及以上依次 `++`。强化参数经 `PromotionData.skill_params` 配置。
- **职业技能与大招同属职业层，允许联动**（如骑兵蓄力 ↔ 骑兵大招击杀返怒）；角色技能层与职业层解耦（仅允许怒气资源类间接关联）。
- **三层边界（可叠加，各有强度预算）**：特性=角色身份被动；大招=职业怒气主动；技能=转职成长被动。普攻/技能/大招分强度预算（NUMBERS.md 10.x）。
- **档位系数**：`s = 1 + 0.1 × min(档/5, 4)`（每 5 档 +10%、上限 4 档 +40%）；档位口径见第 5 节。

## 3. 职业技能明细

### 3.1 骑兵 · 蓄力（charge）

- **职业定位**：短射程、高单体伤害，道路转角压制精英；大招 `ultimate_cavalry_breaker` = 3×普攻单体斩杀、击杀返还 50% 怒气（职业基础）。
- 基础：大招击杀 → 返还怒气 50%×s（与职业大招"击杀返怒"同源，形成大招连发循环）。
- `蓄力+`（二转示例）：武圣 = 返怒 70%×s；青龙骑 = 返怒 50%×s + **击杀后下一次攻击 +20%×s**（快攻连击，融合原 `dragon_rush` 机制）。
- 演出：大招名飘字。

### 3.2 剑客 · 统军令（command）

- **职业定位**：便宜、稳定、手长的近战基础职业，团队基石；大招 `ultimate_pikeman_sweep` = 范围内 1.5×普攻伤害 + 击退 40px。
- 基础：常驻光环 → 周围 150px 友方伤害 +4%×s（自身不吃）。
- `统军令+`：半径/数值提升（数值待实测）。
- 演出：光环（无飘字）。
- 选型说明：剑客 3 名武将（张飞/刘备/周仓）通用性最好的技能；原凶威/斩获因"每职业一技能"收敛移除。

### 3.3 弓箭手 · 稳射（steady）

- **职业定位**：长射程、稳定输出，覆盖道路前后两端；大招 `ultimate_archer_volley` = 4 箭连射（0.8×普攻），优先低血量。
- 基础：**保底追加（v0.2 优化）**——每 5 次攻击必触发一次 0.6×s 追加伤害（原 20% 纯概率，保底后体感稳定；数值待实测）。
- `稳射+`：追加倍率提升（如 0.8×s，待实测）。
- 演出="稳射"飘字+扩散环+音效。

### 3.4 术士 · 奇谋（wisdom）

- **职业定位**：范围法术 + 减速控制敌群，弥补物理输出空窗；大招 `ultimate_strategist_blaze` = 目标区域 2×普攻范围伤害 + 减速 40%/2s。
- 基础：大招释放 → 大招范围 +10%×s（与术士大招 AOE 协同）。
- `奇谋+`：范围加成提升（待实测）。
- 演出="奇谋"飘字。

### 3.5 舞娘 · 鼓舞（inspire）

- **职业定位**：鼓舞邻近人物攻速，直接伤害较低（辅助）；大招 `ultimate_dancer_encourage` = 全队攻速 +30%、伤害 +15%，持续 8s。
- 基础：大招释放 → 全队攻速 +6%×s，持续 8 秒（与职业大招全队 buff 叠加成"双 buff 爆发"）。
- `鼓舞+`：数值/时长提升（待实测）。
- 演出="鼓舞"飘字。

### 3.6 投石车 · 破城（siege）

- **职业定位**：远距离范围压制，攻速极慢、近距离无法攻击；大招 `ultimate_catapult_barrage` = 3 连发快速抛射（0.8×普攻/发）。
- 基础：常驻 → 对精英/Boss 伤害 +10%×s（攻坚定位）。
- `破城+`：数值提升（待实测）。
- 演出：无。
- 名称说明：v0.2 由"攻城锤"改名"破城"（抛石破城，贴合投石车职业；ID 不变）。

- **数据与实现同步**：`PromotionData.skill_params` 收敛为 6 技能、二转参数强化；`SkillRegistry` 移除 3 个废弃技能钩子（`on_attack_hit` 的 ferocity 分支、`on_kill` 的 bulwark/dragon_rush 分支）；显示名 `+`/`++` 规则实现（如 `SKILL_NAMES` 存基础名，按转职层级追加）。
- **档位口径（待拍板）**：设计意图="技能强度绑定武将等级、每 5 级一档"；`SkillRegistry.tier_multiplier()` 目前按局内升阶 `battle_rank` 计算，而第一章升阶上限 3 阶 < 5，实际 `s` 恒为 1（档位系统当前不生效）。
- **数值全部待实测**：+ 级强化参数、稳射保底档位、破城/奇谋/鼓舞强化幅度，需按强度预算（普攻/技能/大招/角色技能分预算）校准，防过强或过弱。
