## 1. 定位与原则

- **技能 = 转职授予的被动/条件触发能力**：由 `SkillRegistry`（`scripts/combat/SkillRegistry.gd`）按 `skill_id` 分发；战斗脚本只调用钩子（`on_attack_hit` / `on_kill` / `on_ultimate_cast` / `on_ally_damaged` / 被动倍率），不写死任何技能逻辑。数值经 `PromotionData.skill_params` 读取。
- **职业技能归属职业且每职业一个核心技能**：6 职业各对应 1 个**核心技能**（一转授予），代表**职业身份**；同职业任意角色共享同一转职树，角色只是技能的当前授予载体。
- **转职双轨（v0.4）**：一转 = 核心技能（基础）；二转分支 = **强化（同名 `+`）**或**新技能（独立 `skill_id`）**，按分支定位配置，不做"所有转职都是强化"。强化/新技能参数均经 `PromotionData.skill_params` 配置。
- **转职为职业级统一**：6 职业 ×（一转唯一 → 二转 2 分支选 1）；角色差异化由**特性 + 角色技能**承担（现有 9+9 已设计）；角色专属转职（三转+）【远期】，现阶段以**角色称号**记录（CHARACTERS.md 4.5）。
- **职业技能与大招同属职业层，允许联动**（如骑兵蓄力 ↔ 骑兵大招击杀返怒、虎贲军旗 ↔ 破阵激励）；角色技能层与职业层解耦（仅允许怒气资源类间接关联）。
- **三层边界（可叠加，各有强度预算）**：特性=角色身份被动；大招=职业怒气主动；技能=转职成长被动。普攻/技能/大招/角色技能分强度预算（NUMBERS.md 10.x）。
- **档位系数**：`s = 1 + 0.1 × min(battle_rank / 5, 4)`（✅ v0.27.4 拍板：仅职业技能适用、按局内升阶；每 5 档 +10%、上限 4 档 +40%）。

## 3. 职业技能明细

### 3.1 骑兵 · 蓄力（charge）

- **职业定位**：短射程、高单体伤害，道路转角压制精英；大招 `ultimate_cavalry_breaker` = 3×普攻单体斩杀、击杀返还 50% 怒气（职业基础）。
- 基础：大招击杀 → 返还怒气 50%×s（与职业大招"击杀返怒"同源，形成大招连发循环）。
- `蓄力+`（玄甲）：返怒 70%×s（重装爆发，强化大招连发循环）。
- `突袭`（骁骑）：击杀后下一次攻击 +25%×s（快攻连击，融合原 `dragon_rush` 机制）。
- 演出：大招名飘字。

### 3.2 虎贲 · 军旗（command）

- **职业定位（v0.27.2 重构）**：近战 buff 类——近战前线 + 士气增益，半输出半辅助；与骑兵互补（骑兵贵、爆发、短程；虎贲便宜、均衡、上前线给队友增益）。大招 `ultimate_tiger_guard_sweep` **破阵** = 范围内 1.5×普攻伤害 + 击退 40px + **附近 200px 友方攻速 +15% 持续 5s**（激励段，数值待实测）。
- 基础：常驻光环 → 周围 150px 友方伤害 +4%×s（军旗所在、士气高昂；自身不吃）。
- `军旗+`（陷阵）：友方伤害 +6%×s、光环半径 180px。
- `护卫`（虎卫）：周围 150px 友军受击时，自身分担 10%×s 伤害（抗线定位；新钩子 `on_ally_damaged`）。
- 演出：光环（无飘字）。
- 选型说明：虎贲 3 名武将（张飞/刘备/周仓）共享职业转职树；原凶威/斩获机制移除（角色差异化由角色技能承担，见 CHARACTER_SKILLS.md）。与舞娘分工：舞娘=远程攻速光环；虎贲=近战伤害/士气光环 + 抗线。

### 3.3 弓箭手 · 稳射（steady）

- **职业定位**：长射程、稳定输出，覆盖道路前后两端；大招 `ultimate_archer_volley` = 4 箭连射（0.8×普攻），优先低血量。
- 基础：**保底追加（v0.2 优化）**——每 5 次攻击必触发一次 0.6×s 追加伤害（原 20% 纯概率，保底后体感稳定；数值待实测）。
- `稳射+`（穿云）：每 5 次攻击必追加 0.8×s。
- `连矢`（连弩）：攻击 20% 概率追加 0.5×s 箭矢（`on_attack_hit` 概率分支，期望增伤约 +10%×s）。
- 演出="稳射"飘字+扩散环+音效。

### 3.4 术士 · 奇谋（wisdom）

- **职业定位**：范围法术 + 减速控制敌群，弥补物理输出空窗；大招 `ultimate_strategist_blaze` = 目标区域 2×普攻范围伤害 + 减速 40%/2s。
- 基础：大招释放 → 大招范围 +10%×s（与术士大招 AOE 协同）。
- `奇谋+`（智囊）：大招范围 +15%×s。
- `奇门`（天师）：每波首次大招后，范围内敌人额外减速 25%×s/3s（与大招自带减速叠成控制窗口；Boss 控制抗性折减生效）。
- 演出="奇谋"飘字。

### 3.5 舞娘 · 鼓舞（inspire）

- **职业定位**：鼓舞邻近人物攻速，直接伤害较低（辅助）；大招 `ultimate_dancer_encourage` = 全队攻速 +30%、伤害 +15%，持续 8s。
- 基础：大招释放 → 全队攻速 +6%×s，持续 8 秒（与职业大招全队 buff 叠加成"双 buff 爆发"）。
- `鼓舞+`（凤仪）：全队攻速 +9%×s，持续 10 秒。
- `余音`（绕梁）：大招释放后，全队伤害 +8%×s，持续 5 秒（与鼓舞攻速互补，形成攻速+伤害双 buff）。
- 演出="鼓舞"飘字。

### 3.6 投石车 · 破城（siege）

- **职业定位**：远距离范围压制，攻速极慢、近距离无法攻击；大招 `ultimate_catapult_barrage` = 3 连发快速抛射（0.8×普攻/发）。
- 基础：常驻 → 对精英/Boss 伤害 +10%×s（攻坚定位）。
- `破城+`（拔城）：对精英/Boss 伤害 +15%×s。
- `震地`（震山）：大招落点范围敌人减速 30%×s/2s（与皇甫嵩角色技能"焚营"灼烧区分，控制向）。
- 演出：无。
- 名称说明：v0.2 由"攻城锤"改名"破城"（抛石破城，贴合投石车职业；ID 不变）。
