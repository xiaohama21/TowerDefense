## 9. UI 与表现

| 界面 | 内容 | 阶段 | 状态 |
|---|---|---|---|
| 主菜单 | 继续出征、新的征程（覆盖存档需确认）、退出 | 阶段1 | ✅ v0.9（`MainMenu.tscn`） |
| 章节选择+关卡选择 | 按章节列出关卡，前置关卡未通关锁定，已通关标注 | 阶段1 | ✅ v0.9（`StageSelect.tscn`） |
| 编队 | 已拥有武将列表、squad_size 上限、出战槽 | 阶段1 | ✅ v0.9（`SquadSelect.tscn`，达上限禁止继续勾选） |
| 战斗 | 建造栏、波次预告、金钱/生命、建造槽、已建塔交互（**属性面板**：地图正下方，展示伤害/攻速/射程与升级/回收，见 modules/STAGES.md 5.4）、**武将怒气条**（阶段5 完善表现） | 阶段1（已有基础） | ✅ 属性面板+升级回收（v0.9.2）；怒气条阶段 3/5 |
| 结算 | 胜利/失败、经验明细、掉落明细、新武将、下一关/重试/返回选关 | 阶段1 | ✅ v0.9（战斗内结算面板） |
| 养成-武将详情 | 等级、经验条、属性、**特性说明**、**大招说明**、转职入口 | 阶段2 | 待开发 |
| 养成-转职 | 条件展示、消耗确认 | 阶段2 | 待开发 |
| 求贤（抽奖） | 卡池、十连、结果展示 | 阶段4 | 待开发 |
| 技能演出 | 弹道、特效、音效 | 阶段5 | 待开发 |

- **流程导航**：场景跳转统一经 `GameFlow`（`goto_menu/goto_stage_select/goto_squad_select/goto_battle`），跨场景临时状态（选中关卡、出战编队）由 `GameFlow` 持有，不落存档。
- **美术**：当前用程序化矢量占位（`EnemyData.body_color`、`body_size` 已有；塔与弹道按职业绘制）；正式立绘【远期】。武将塔与敌人应有明显阵营配色区分。表现层实现细则（职业造型、弹道绘制）随实现演进，不影响本表职责划分。
- **音频**：暂用占位，不阻塞。
- **调试辅助**：调试构建（`OS.is_debug_build()`）自动挂载 `DebugPanel`（加金币、跳波次、清空敌人），仅用于测试，不影响正式数值与结算。
