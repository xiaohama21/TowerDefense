## 9. UI 与表现

| 界面 | 内容 | 阶段 |
|---|---|---|
| 主菜单 | 开始游戏、继续、设置 | 阶段1 |
| 章节选择 | 章节卡片（`is_currently_available` 控制） | 阶段1 |
| 关卡选择 | 关卡节点连线、首通/星标（预留） | 阶段1 |
| 编队 | 已拥有武将列表、squad_size 上限、出战槽 | 阶段1 |
| 战斗 | 建造栏、波次预告、金钱/生命、建造槽、已建塔交互（升级/回收，见 modules/STAGES.md 5.4）、**武将怒气条**（阶段5 完善表现） | 阶段1（已有基础） |
| 结算 | 胜利/失败、经验明细、掉落明细、新武将 | 阶段1 |
| 养成-武将详情 | 等级、经验条、属性、**特性说明**、**大招说明**、转职入口 | 阶段2 |
| 养成-转职 | 条件展示、消耗确认 | 阶段2 |
| 求贤（抽奖） | 卡池、十连、结果展示 | 阶段4 |
| 技能演出 | 弹道、特效、音效 | 阶段5 |

- **美术**：当前用程序化矢量占位（`EnemyData.body_color`、`body_size` 已有；塔与弹道按职业绘制）；正式立绘【远期】。武将塔与敌人应有明显阵营配色区分。表现层实现细则（职业造型、弹道绘制）随实现演进，不影响本表职责划分。
- **音频**：暂用占位，不阻塞。
- **调试辅助**：调试构建（`OS.is_debug_build()`）自动挂载 `DebugPanel`（加金币、跳波次、清空敌人），仅用于测试，不影响正式数值与结算。
