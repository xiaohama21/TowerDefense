- **流程导航**：场景跳转统一经 `GameFlow`（`goto_menu/goto_hub/goto_squad_select/goto_battle`）；游戏大厅为选关/养成/设置的统一入口，跨场景临时状态（选中关卡、当前大厅页签）由 `GameFlow` 持有；**出战编队（武将 + 遗物）自 v0.33.1 起在「确认出战」时持久化**（存档 `squad_character_ids` / `squad_relic_ids`），再次出征自动预填（v0.33.1 前"编队不落存档"表述作废）。
- **美术**：当前用程序化矢量占位（`EnemyData.body_color`、`body_size` 已有；塔与弹道按职业绘制）；正式立绘【远期】。武将塔与敌人应有明显阵营配色区分。表现层实现细则（职业造型、弹道绘制）随实现演进，不影响本表职责划分。
- **音频**（✅ v0.16.0）：程序化音效库 `SfxLibrary`（autoload，运行时合成 16-bit PCM，零外部资产）——普攻/技能/大招/击杀/建造升级/胜利/失败 7 种，走 Master 总线受设置"主音量"控制。
- **调试辅助**：调试构建（`OS.is_debug_build()`）自动挂载 `DebugPanel`（加金币、跳波次、清空敌人）；另有常驻测试入口——地图面板"一键通关"、背包"获得练兵令 ×10"、养成面板"使用练兵令"（v0.15.1）。均仅用于测试，不影响正式数值与结算。
