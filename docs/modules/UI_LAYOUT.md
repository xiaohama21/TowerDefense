## 1. 设计总原则

1. **信息分层**：一个界面只展示当前任务需要的信息；低频/进阶信息（转职、升星、信物、特性、详细数值）通过**页签、折叠或二级弹窗**承载，禁止全部堆在一屏。
2. **一屏一任务**：每个面板聚焦一个操作流程；默认布局在 1280×720 内一屏放得下，主功能区**禁用滚动条**，滚动只允许出现在内容确实超长的次级区域。
3. **网格优先**：同类条目（关卡、武将、道具）一律用固定列数网格（`GridContainer`），列数按内容数与一屏容量设定，不依赖竖排列表+滚动。
4. **关键信息强调**：关键信息统一使用语义色高亮（见第 2 节），玩家扫一眼即可区分"可做 / 已做 / 不可做 / 数值"。
5. **拓展空间**：所有面板为后续功能预留位——页签可增、网格可加列/翻页、卡片可加角标；**新增功能只增不重构**。
6. **交互反馈**：每个可交互元素具备 hover / 按下 / 选中 / 禁用四种明确状态；点击目标 ≥ 40×40px；操作有即时反馈（颜色变化 / 音效 / 飘字）。

## 2. 语义色板（全局统一，收敛为共享常量）

| 语义 | 色值 | 用途 |
|---|---|---|
| 强调 / 主色（金） | `0.92, 0.78, 0.42` | 标题、关键资源（金钱/科技点/材料）、可解锁、选中态 |
| 成功 / 达标（绿） | `0.55, 0.92, 0.80` | 已解锁、已通关、可升级、材料充足、胜利 |
| 警示 / 不足（红） | `0.90, 0.45, 0.40` | 锁定、材料不足、生命告急、失败、Boss 预警 |
| 信息 / 数值（蓝） | `0.65, 0.84, 1.00` | 属性数值、说明文字、经验 |
| 次级文字（灰） | `0.70, 0.72, 0.68` | 提示、占位、未解锁说明 |
| 底色（深） | `0.06, 0.09, 0.08` / 侧栏 `0.09, 0.13, 0.11` | 界面背景与侧栏 |

- 所有面板引用**同一色板常量**（新增 `scripts/ui_screens/ui_theme.gd`，静态常量或 autoload）；重构时删除各面板私有的 `TITLE_COLOR / OK_COLOR / BAD_COLOR` 等重复定义，禁止私有魔数颜色。
- 相同语义必须同色：例如"材料不足"在养成、科技树、编队中均为红色，不因面板不同而换色。

## 4. 地图选关（MapPanel）——本提交重点重构

**现状问题**：章节区竖排 + 190px 滚动条，"敬请期待"占位挤占空间；关卡区竖排 + 滚动，信息密度低。

**新布局**：
- **章节区**：横向一行胶囊按钮（第一章=可点击；后续章节=锁定灰显"敬请期待"），高度固定 56px，**不滚动**；章节 ≤7 个时一行放得下，超出自动换行（仍不出现滚动条）。
- **关卡区**：**`GridContainer` 2 列 × 4 行**，卡片式按钮约 320×120px，一屏展示 8 关，**无滚动条**。卡片内容：
  - 关卡名（章节战役名）+ 副标题（主题/教学点摘要，灰字小号）。
  - 状态角标：锁定 🔒（灰）/ 可挑战（金边框）/ 已通关（绿钩 + 星级 ★0~3，星级为阶段 10 挑战目标预留位）。
  - 首通奖励小字（分标签展示：解锁武将：xxx；道具×N；信物：xxx，v0.30.2）。
- 选中关卡后，**底部操作条**：关卡信息摘要（含**当前难度**，v0.30.2）+ 难度切换（**标准/困难两档互斥单选**，默认标准；选中=金色高亮；档位随 `difficulty_presets` 自动扩展，v0.31.2）+「出征」主按钮（金色，**点击直达编队**——原 v0.31.2 确认弹窗删除，防误触确认收敛到编队页「确认出战」，v0.33.1）+「一键通关（测试）」小按钮（灰字，测试辅助；结果提示在刷新/切换时自动清除，v0.30.2）。
- 分辨率内一屏完整，不出现任何滚动条。

## 5. 武将养成（DevelopPanel）——页签化重构

**现状问题**：单面板堆叠全部信息（等级/属性/一转/升星/遗物/求贤），信息过载、无拓展空间。

**新布局**：
- **左侧武将列表**：网格 2 列卡片（头像占位 / 姓名 / 职业 / 等级；**每次切回面板整体重载**——新增武将与等级随档案实时刷新，v0.32.1）；未解锁=图鉴灰卡（显示获取方式）；选中金色边框。
- **右侧上半=基础信息卡**（只展示基础信息）：等级 + 经验条、职业、**角色称号（金色小字）**、当前属性摘要（伤害 / 攻速 / 射程，蓝色数值）。
- **右侧下半=页签区（TabBar）**，进阶信息全部经页签切换：
  - 「转职」：一转/二转路线、材料需求、技能说明（现有转职流程迁入；转职操作带**确认弹窗**——提示不可逆、展示目标职业，确认 / 取消 / 右上角关闭均正确释放，v0.32.2）。
  - 「升星」：星级展示、碎片数量、升星按钮与效果说明（现有升星区迁入；**随 v0.30.0 暂时移除**）。
  - 「信物」：信物装备 / 更换（现有信物区迁入；信物 = 武将专属，与队伍级遗物区分，v0.33.1）。
  - 「遗物」：**随 v0.33.1 移除页签**——遗物为队伍级：选带在编队页 §6、库存与效果说明在背包页 §8「遗物」类目；不再作为武将页签展示（原只读库存说明迁至背包页）。
  - 「特性」（预留页签）：角色常驻特性说明，阶段 9 升阶特性接入时直接挂载，不改布局。
- **求贤（抽奖）**：从养成页移除作为独立入口（侧栏新增"求贤"按钮或养成页右上角按钮弹窗），不再占用养成主区；**随 v0.30.0 暂时移除（入口关闭，恢复时按本设计接入）**。
- 未来新增角色功能 = 新增页签，**不动既有布局**。

## 6. 编队（SquadSelect）——纵向分区定稿（v0.33.1）

- **整体纵向分区**（自上而下，1280×720 一屏无滚动；未来新系统（如器械/计略等）在武将区与遗物区之间追加分区，**只增不改**）：
  - **标题区**：显示所选关卡名 + 难度（从选关页带入，如"第一章 · 第 1 关 黄巾之乱（标准）"），便于确认当前出征目标。
  - **武将选择区**：已拥有武将网格（4 列卡片，头像 / 姓名 / 职业 / 等级，样式与养成页一致）；点击卡片**选中/取消**，最多 `squad_size` 名，已选卡金边 + 显示羁绊标签，满员后其余卡片置灰；顶部小字显示已选 `n / squad_size`；卡片宽 **232px**（v0.33.2 防双羁绊标签裁剪），羁绊 X/Y 预览随勾选实时刷新。
  - **羁绊提示条**：金色小字，如"桃园结义 2/3 已激活：攻击 +5%"；未激活则灰字提示"已选武将暂无羁绊"。
  - **遗物选带区**：横向卡片，最多 2 件，卡片含名称 + 效果 + **「永久使用」标记**（v0.33.1 起选带不消耗库存、可反复携带）；无库存时显示空位灰卡。
  - **底部固定操作条**：「返回选关」（左下，次级样式）——返回选关页并**保留所选关卡与难度**；「确认出战」（右下，金色主按钮，v0.33.1 由「出征」更名）。
- **「确认出战」二次确认弹窗（v0.33.1 防误触收敛点）**：展示 关卡名 / 难度 / 出战武将名单（含职业与等级）/ 遗物清单（注明永久使用不消耗）与简短说明；确认后 `goto_battle()` 正式进入游戏；取消 / 关闭回到编队可继续调整。
- **编队记忆自动预填（v0.33.1）**：确认出战即把编队写入玩家存档（`squad_character_ids` / `squad_relic_ids`）；再次进入编队页时自动预填上次出战配置——武将须仍拥有、遗物须仍有库存，超上限 / 缺失项自动裁剪，无匹配则空槽显示。

## 9. 战斗界面（Main / UI）

- 顶栏（左→右）：金钱（金色）、基地生命（≤30% 变红脉动）、当前波次/总波次；按钮：军需、设置、自动开波开关。
- 武将卡片面板（v0.33.3 重设计）：横向排列出战武将卡——武将名 / 职业全名 / Lv（蓝）/ 费用（金）；卡片即**拖拽手柄**（按住左键拖出建造，按下金色高亮）；金币不足置灰 + 红色费用、不可拖；无“选中武将”概念（原 toggle 选中态删除）。
- **拖拽建造（v0.33.3 定稿，唯一建造方式）**：除道路 / 禁建地形 / 已占用格外的任意空地均可建；按住武将卡片拖出后——**角色虚影**（与实塔同款表现、半透明）+ **攻击范围圈**（等级 / 转职 / 特性 / 遗物计算后的实际射程）跟随鼠标；落点格整格高亮：**可建=绿、不可建=红**（道路 / 禁建 / 已占用 / 越界 / 金币不足 / 战后）；**松手直接建造**（与旧点击路径同一 build_tower 链路，扣费 / 上塔 / 音效一致），右键 / ESC / 原地松手取消；拖入顶栏 / 卡条等 UI 区域虚影隐藏、松手取消。绿色 + 推荐位、预锁位、hover 可建预览（B-021）一并移除。
- 已建塔属性面板：属性数值（蓝色）、升阶/回收/大招按钮；升阶可升=金色高亮，材料/费用不足=红色。
- 结算页（自上而下）：胜利/失败横幅（绿/红）→ 奖励明细（经验、掉落、新武将）→ 目标勾选与星级（阶段 10 预留位）→ 结算转盘（提交 2）→ 下一关 / 重试 / 返回大厅。
- Boss 预警横幅：红色警示 + 登场演出（沿用 v0.15.0）。

## 11. 验收标准（阶段 8·提交 4）

- 地图选关：第一章 8 关 **2×4 网格一屏展示、无滚动条**；章节一行可点，锁定章节不挤占主区。
- 武将养成：基础信息一屏可见；转职 / 信物 / 特性（预留）经页签可达（升星页签随 v0.30.0、遗物页签随 v0.33.1 移除——遗物为队伍级：选带在编队页 §6、库存与效果在背包页 §8）；新增页签不改布局。
- 出征链路（v0.33.1）：选关页「出征」直达编队（无弹窗）；编队页「返回选关」保留关卡与难度；「确认出战」二次确认弹窗展示关卡/难度/武将名单/遗物清单，确认后才进入游戏；再次出征自动预填上次编队（武将 + 遗物）。
- 全局：语义色收敛为共享色板常量，各面板无私有颜色魔数；关键信息（金钱、科技点、材料不足、锁定、Boss 预警）颜色语义正确。
- 建造（v0.33.3）：拖拽为唯一建造方式——卡片拖出后虚影 / 攻击范围圈 / 绿红落点格反馈齐全；松手直建、右键与 ESC 取消；绿色 + 与预锁位不再出现。
- 回归：流程测试（解锁 / 编队 / 布局规范）与冒烟测试全绿，一键通关与结算链路不受影响。
