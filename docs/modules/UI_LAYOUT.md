## 1. 设计总原则

1. **信息分层**：一个界面只展示当前任务需要的信息；低频/进阶信息（转职、升星、信物、特性、详细数值）通过**页签、折叠或二级弹窗**承载，禁止全部堆在一屏。
2. **一屏一任务**：每个面板聚焦一个操作流程；默认布局在 1280×720 内一屏放得下，主功能区**禁用滚动条**，滚动只允许出现在内容确实超长的次级区域。
3. **网格优先**：同类条目（关卡、武将、道具）一律用固定列数网格（`GridContainer`），列数按内容数与一屏容量设定，不依赖竖排列表+滚动。
4. **关键信息强调**：关键信息统一使用语义色高亮（见第 2 节），玩家扫一眼即可区分"可做 / 已做 / 不可做 / 数值"。
5. **拓展空间**：所有面板为后续功能预留位——页签可增、网格可加列/翻页、卡片可加角标；**新增功能只增不重构**。
6. **交互反馈**：每个可交互元素具备 hover / 按下 / 选中 / 禁用四种明确状态；点击目标 ≥ 40×40px；操作有即时反馈（颜色变化 / 音效 / 飘字）。

## 2. 语义色板（全局统一，收敛为共享常量）

| 语义 | 色值 | 用途 |
|---|---|---|
| 强调 / 主色（金） | `0.92, 0.78, 0.42` | 标题、关键资源（金钱/科技点/材料）、可解锁、选中态 |
| 成功 / 达标（绿） | `0.55, 0.92, 0.80` | 已解锁、已通关、可升级、材料充足、胜利 |
| 警示 / 不足（红） | `0.90, 0.45, 0.40` | 锁定、材料不足、生命告急、失败、Boss 预警 |
| 信息 / 数值（蓝） | `0.65, 0.84, 1.00` | 属性数值、说明文字、经验 |
| 次级文字（灰） | `0.70, 0.72, 0.68` | 提示、占位、未解锁说明 |
| 底色（深） | `0.06, 0.09, 0.08` / 侧栏 `0.09, 0.13, 0.11` | 界面背景与侧栏 |

- 所有面板引用**同一色板常量**（新增 `scripts/ui_screens/ui_theme.gd`，静态常量或 autoload）；重构时删除各面板私有的 `TITLE_COLOR / OK_COLOR / BAD_COLOR` 等重复定义，禁止私有魔数颜色。
- 相同语义必须同色：例如"材料不足"在养成、科技树、编队中均为红色，不因面板不同而换色。

## 3. 大厅布局（GameHub）

- 左侧功能栏固定 250px：图标+文字按钮纵向排列（地图 / 养成 / 科技 / 背包 / 设置 / 返回主菜单）；**选中态金色高亮 + 左侧金色竖条**，未选中为灰色文字。
- 右侧内容区：内容面板统一 MarginContainer 内边距（左右 24 / 上下 32），标题统一 28px 金色。
- 预留：侧栏按钮可新增（如后续"挑战"入口；"求贤"独立入口随抽将暂时移除 v0.30.0），新增只加按钮不改结构。

## 4. 地图选关（MapPanel）——本提交重点重构

**现状问题**：章节区竖排 + 190px 滚动条，"敬请期待"占位挤占空间；关卡区竖排 + 滚动，信息密度低。

**新布局**：
- **章节区**：横向一行胶囊按钮（第一章=可点击；后续章节=锁定灰显"敬请期待"），高度固定 56px，**不滚动**；章节 ≤7 个时一行放得下，超出自动换行（仍不出现滚动条）。
- **关卡区**：**`GridContainer` 2 列 × 4 行**，卡片式按钮约 320×120px，一屏展示 8 关，**无滚动条**。卡片内容：
  - 关卡名（章节战役名）+ 副标题（主题/教学点摘要，灰字小号）。
  - 状态角标：锁定 🔒（灰）/ 可挑战（金边框）/ 已通关（绿钩 + 星级 ★0~3，星级为阶段 10 挑战目标预留位）。
  - 首通奖励小字（分标签展示：解锁武将：xxx；道具×N；信物：xxx，v0.30.2）。
- 选中关卡后，**底部操作条**：关卡信息摘要（含**当前难度**，v0.30.2）+ 难度切换（轻松/标准/困难，默认标准）+「出征」主按钮（金色）+「一键通关（测试）」小按钮（灰字，测试辅助；结果提示在刷新/切换时自动清除，v0.30.2）。
- 分辨率内一屏完整，不出现任何滚动条。

## 5. 武将养成（DevelopPanel）——页签化重构

**现状问题**：单面板堆叠全部信息（等级/属性/一转/升星/遗物/求贤），信息过载、无拓展空间。

**新布局**：
- **左侧武将列表**：网格 2 列卡片（头像占位 / 姓名 / 职业 / 等级）；未解锁=图鉴灰卡（显示获取方式）；选中金色边框。
- **右侧上半=基础信息卡**（只展示基础信息）：等级 + 经验条、职业、当前属性摘要（伤害 / 攻速 / 射程，蓝色数值）。
- **右侧下半=页签区（TabBar）**，进阶信息全部经页签切换：
  - 「转职」：一转/二转路线、材料需求、技能说明（现有转职流程迁入）。
  - 「升星」：星级展示、碎片数量、升星按钮与效果说明（现有升星区迁入；**随 v0.30.0 暂时移除**）。
  - 「信物」：信物装备 / 更换（现有信物区迁入）。
  - 「遗物」：局内遗物库存与效果说明（只读；选带在编队页）。
  - 「特性」（预留页签）：角色常驻特性说明，阶段 9 升阶特性接入时直接挂载，不改布局。
- **求贤（抽奖）**：从养成页移除作为独立入口（侧栏新增"求贤"按钮或养成页右上角按钮弹窗），不再占用养成主区；**随 v0.30.0 暂时移除（入口关闭，恢复时按本设计接入）**。
- 未来新增角色功能 = 新增页签，**不动既有布局**。

## 6. 编队（SquadSelect）

- 左侧：已拥有武将网格（卡片样式与养成页一致）。
- 中部：出战槽位（`squad_size` 个，横向排列）；已选武将卡显示羁绊标签；空槽=虚线框"+"；满员后其余武将卡置灰。
- 底部：羁绊激活提示条（金色，如"桃园结义 2/3 已激活：攻击 +5%"）+ **遗物选带区**（折叠展开，默认收起，最多 2 件）。
- 「出征」按钮常驻右下，金色高亮；返回按钮左下。

## 7. 科技树（TechPanel，配合提交 3 分类重构）

- 顶部：科技点余额（金色大字，醒目）+「重置」按钮（无条件重置，点击弹确认框）。
- **四页签**：军略 / 后勤 / 工事 / 将略（v0.23.0 拍板定名）。
- **树状布局（v0.30.2 重构）**：按前置链分列（同一列 = 同一链），列内按 tier 从上到下排列、节点间竖线连接；节点仅显示成语名 + 状态（已解锁 ✓ 绿 / 解锁点数金 / 需前置灰锁）；点击节点在底部详情面板展示摘要 + 描述 + 解锁操作（解锁按钮随状态切换；数值含在描述文案中，不再单独输出 effect 键）。
- 预留：页签可扩展，后续新分类直接加页签。

## 8. 背包（InventoryPanel）

- 道具网格卡片：图标（程序化占位）+ 名称 + 数量角标（金色）。
- 顶部筛选：全部 / 材料 / 碎片 / 遗物（抽奖券类目随求贤暂时移除 v0.30.0）。
- 描述查看：悬停 tooltip 或选中后底部说明条，避免卡片内堆长文本。

## 9. 战斗界面（Main / UI）

- 顶栏（左→右）：金钱（金色）、基地生命（≤30% 变红脉动）、当前波次/总波次；按钮：军需、设置、自动开波开关。
- 建造栏：职业卡片（图标 + 建造费用；金币不足=置灰 + 红色费用）。
- 已建塔属性面板：属性数值（蓝色）、升阶/回收/大招按钮；升阶可升=金色高亮，材料/费用不足=红色。
- 结算页（自上而下）：胜利/失败横幅（绿/红）→ 奖励明细（经验、掉落、新武将）→ 目标勾选与星级（阶段 10 预留位）→ 结算转盘（提交 2）→ 下一关 / 重试 / 返回大厅。
- Boss 预警横幅：红色警示 + 登场演出（沿用 v0.15.0）。

## 10. 设置（SettingsPanel）

- 分区（画面 / 音频 / 玩法）折叠分组；开关 + 滑块控件；当前值高亮（蓝色），改动即时生效并持久化（沿用 settings.cfg）。

## 11. 验收标准（阶段 8·提交 4）

- 地图选关：第一章 8 关 **2×4 网格一屏展示、无滚动条**；章节一行可点，锁定章节不挤占主区。
- 武将养成：基础信息一屏可见；转职 / 信物 / 遗物 / 特性全部经页签可达（升星页签随 v0.30.0 暂时移除）；新增页签不改布局。
- 全局：语义色收敛为共享色板常量，各面板无私有颜色魔数；关键信息（金钱、科技点、材料不足、锁定、Boss 预警）颜色语义正确。
- 交互：所有按钮具备四种状态；点击目标 ≥40px；操作有即时反馈。
- 回归：流程测试（解锁 / 编队 / 布局规范）与冒烟测试全绿，一键通关与结算链路不受影响。

## 12. 不做什么

- 不做正式美术素材（立绘 / 图标仍为程序化占位，见总纲【远期】）。
- 不做移动端/窗口自适应（分辨率固定 1280×720）。
- 不重做战斗场景布局（`Main.tscn` 已有基础，仅按本规范调整色板与信息层级）。
- 星级展示仅预留 UI 位，挑战目标系统本体在阶段 10 开发。
