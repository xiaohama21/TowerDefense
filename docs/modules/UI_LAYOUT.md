## 1. 设计总原则

1. **信息分层**：一个界面只展示当前任务需要的信息；低频/进阶信息（转职、升星、信物、特性、详细数值）通过**页签、折叠或二级弹窗**承载，禁止全部堆在一屏。
2. **一屏一任务**：每个面板聚焦一个操作流程；默认布局在 1280×720 内一屏放得下，主功能区**禁用滚动条**，滚动只允许出现在内容确实超长的次级区域。
3. **网格优先**：同类条目（关卡、武将、道具）一律用固定列数网格（`GridContainer`），列数按内容数与一屏容量设定，不依赖竖排列表+滚动。
4. **关键信息强调**：关键信息统一使用语义色高亮（见第 2 节），玩家扫一眼即可区分"可做 / 已做 / 不可做 / 数值"。
5. **拓展空间**：所有面板为后续功能预留位——页签可增、网格可加列/翻页、卡片可加角标；**新增功能只增不重构**。
6. **交互反馈**：每个可交互元素具备 hover / 按下 / 选中 / 禁用四种明确状态；点击目标 ≥ 40×40px；操作有即时反馈（颜色变化 / 音效 / 飘字）。

## 2. 语义色板（全局统一，收敛为共享常量）

| 语义 | 色值 | 用途 |
|---|---|---|
| 强调 / 主色（金） | `0.92, 0.78, 0.42` | 标题、关键资源（金钱/科技点/材料）、可解锁、选中态 |
| 成功 / 达标（绿） | `0.55, 0.92, 0.80` | 已解锁、已通关、可升级、材料充足、胜利 |
| 警示 / 不足（红） | `0.90, 0.45, 0.40` | 锁定、材料不足、生命告急、失败、Boss 预警 |
| 信息 / 数值（蓝） | `0.65, 0.84, 1.00` | 属性数值、说明文字、经验 |
| 次级文字（灰） | `0.70, 0.72, 0.68` | 提示、占位、未解锁说明 |
| 底色（深） | `0.06, 0.09, 0.08` / 侧栏 `0.09, 0.13, 0.11` | 界面背景与侧栏 |

- 所有面板引用**同一色板常量**（新增 `scripts/ui_screens/ui_theme.gd`，静态常量或 autoload）；重构时删除各面板私有的 `TITLE_COLOR / OK_COLOR / BAD_COLOR` 等重复定义，禁止私有魔数颜色。
- 相同语义必须同色：例如"材料不足"在养成、科技树、编队中均为红色，不因面板不同而换色。

## 7. 编队（SquadSelect）——纵向分区定稿（v0.33.1）

- **整体纵向分区**（自上而下，1280×720 一屏无滚动；未来新系统（如器械/计略等）在武将区与遗物区之间追加分区，**只增不改**）：

## 13. 验收标准（阶段 8·提交 4）

- 地图选关：第一章 8 关 **2×4 网格一屏展示、无滚动条**；章节一行可点，锁定章节不挤占主区。
- 武将养成：基础信息一屏可见；转职 / 信物 / 特性（预留）经页签可达（升星页签随 v0.30.0、遗物页签随 v0.33.1 移除——遗物为队伍级：选带在编队页 §7、库存与效果在背包页 §9）；新增页签不改布局。
- 出征链路（v0.33.1）：选关页「出征」直达编队（无弹窗）；编队页「返回选关」保留关卡与难度；「确认出战」二次确认弹窗展示关卡/难度/武将名单/遗物清单，确认后才进入游戏；再次出征自动预填上次编队（武将 + 遗物）。
- 全局：语义色收敛为共享色板常量，各面板无私有颜色魔数；关键信息（金钱、科技点、材料不足、锁定、Boss 预警）颜色语义正确。
- 建造（v0.33.3）：拖拽为唯一建造方式——卡片拖出后虚影 / 攻击范围圈 / 绿红落点格反馈齐全；松手直建、右键与 ESC 取消；绿色 + 与预锁位不再出现。
- 回归：流程测试（解锁 / 编队 / 布局规范）与冒烟测试全绿，一键通关与结算链路不受影响。

## 14. 不做什么

- 不做正式美术素材（立绘 / 图标仍为程序化占位，见总纲【远期】）。
- 不做移动端/窗口自适应（分辨率固定 1280×720）。
- 不重做战斗场景布局（`Main.tscn` 已有基础，仅按本规范调整色板与信息层级）。
- 星级展示仅预留 UI 位，挑战目标系统本体在阶段 10 开发。
