## 1. 分层模型与三类数学关系

### 1.1 五层计算顺序（NUMBERS.md 10.10 落地细化）

```text
L0 基础属性        → 职业数据（base_damage / base_range / attack_interval / min_range）+ 角色基础
L1 局外成长        → 等级（成长系数×级差）、转职（PromotionData 三围倍率）、星级（v0.30.0 停用）、信物（射程加值/攻速因子/伤害%）
L2 编队加成        → 羁绊（桃园 +5%）、科技（全局伤害 cap ±15%、职业分支 ≤10%、攻速/怒气/buff 强度等）
L3 本局开局加成    → 遗物（编队选带 2 件：伤害% 相加、射程% 相加、攻速因子相乘、金币/生命相加）
L4 本局动态加成    → 升阶 battle_rank（职业步进×阶数）、军需、连击、职业技能、大招、角色技能、特性、常驻光环、目标减益
L5 最终限幅        → 攻速下限 0.55、各桶上限、Boss 控制抗性、怒气上限 100
```

### 1.2 三类数学关系（本文件核心约定）

1. **跨层乘法**：L0→L5 相邻层之间原则上相乘——保证等级/转职/科技/遗物成长各自可感，不做全局拉平（v0.22.0 拍板）。
2. **层内同类加法 + 桶上限**：同一层内、语义相同（同为「友方攻速增益」「友方伤害增益」）的来源，必须进同一桶**加法求和**并受桶上限约束；**同类禁止各自乘算**（防「同类光环逐项相乘」的指数膨胀）。
3. **目标条件 / 一次性爆发乘法 + 单项预算**：条件增伤（对特定标签/血量/状态的敌人）与一次性爆发（蓄力下一击等）允许乘算——它们不是「光环」，互斥性强；但每项必须有预算上限（档次 3，见第 9 节），禁止无预算新增乘点。

## 2. 伤害结算管线（`Tower.finalize_damage`）

### 2.1 公式（收敛后目标形态；标注为「→ 档次 N」的项为收敛点）

```text
最终伤害 = 攻击基准伤害(damage)
  ×（1 + 临时伤害桶 Σ）                          ← L4 临时施放类（舞娘大招等），加法 clamp [+0, +100%]（✅ 现状）
  ×（1 + 常驻光环伤害桶 Σ）                      ← L4 常驻光环（仁德 8% + 军旗：一转 4%×s/个、军旗+ 6%×s/个），加法 clamp [0, +50%] ✅ 档次 1 落地（提交 7）
  ×（1 + 编队加成伤害桶 Σ）                      ← L2 科技全局% + 科技职业分支% + 羁绊%，加法 clamp [0, +30%] ✅ 档次 2 落地（提交 10）
  ×（1 + 信物伤害% ）                            ← L1 信物（跨层保留乘算）
  ×（1 + 局内遗物伤害% Σ）                       ← L3 遗物（多件相加，跨层保留乘算）
  × 职业克制倍率                                  ← L4 条件增伤（虎贲对 cavalry ×1.15）
  × 条件增伤乘区（特性 × 技能被动 × 目标易伤）    ← L4 条件增伤（单项 ≤+30% 预算 → 档次 3）
  ×（1 + 一次性爆发%）                           ← L4（蓄力+ 下一击等，触发即消耗）
```

### 2.2 攻击基准伤害 `damage` 的来源链（L0→L1→L4·升阶）

1. **L0/L1 基础**：`CharacterData.compute_stats_at()`（scripts/data/CharacterData.gd）——
   `基准伤害 = (base_damage + 成长系数 ×(1+0.05×星级[停用恒 0]) ×(等级-1)) × 转职伤害倍率`，入战存档 `_base_damage`。
2. **L4 升阶**：`apply_battle_rank()`（scripts/Tower.gd:283）——
   `当前 damage = _base_damage ×(1 + 职业伤害步进 × battle_rank)`；步进取 `CharacterData.battle_rank_*_override`（-1 继承职业默认 `ProfessionData.battle_rank_damage_step`，默认 0.25）。
3. 大招、技能、弹道的原始值都以该 `damage` 为基数乘各自倍率（如大招 = damage ×N×`ultimate_power()`），随后全部进入 `finalize_damage` 管线（普攻/技能/大招共用同一尾段乘区——注意大招同样吃光环/特性/克制，强度预算见 10.10「普攻/技能/大招分预算」与 SKILLS.md 4.1 大招倍率）。

### 2.3 收敛前现状（代码快照，v0.31.5）与差异

现状 `finalize_damage`（scripts/Tower.gd:697-712）：

```text
base × damage_buff
  ×(1+信物) ×(1+科技全局) ×(1+科技职业分支) ×(1+羁绊) ×(1+局内遗物)
  × 职业克制 ×(1+仁德 8%) × 特性倍率 × passive_damage_multiplier(军旗×破城×定军山) ×(1+蓄力)
```

与 2.1 目标形态的差异即三档收敛点：
- 仁德、军旗从「尾段独立乘」移入常驻光环伤害桶（档次 1）；多虎贲由 ×1.06^n 变 ×(1+0.06×s×n)，与仁德同桶加法。
- 科技全局/科技职业/羁绊由「首行 3 连乘」合并为编队桶（档次 2）；数值差异仅在非零加成时约 -1~2%（如全满 1.15×1.10×1.05=1.328 → 1+0.30=1.30），消除的是「同层叠乘」的语义错误而非大削。
- 破城/定军山/特性/克制留在条件乘区，但登记预算表（档次 3）。

## 3. 攻速结算管线（`Tower._rebuild_attack_timer`）

```text
攻击间隔计时 = attack_cooldown
  ÷（临时攻速桶 attack_speed_buff）              ← 加法 clamp [+0, +100%]（✅ 现状）
  ÷（1 + 0.04 × 赵云龙魂叠层）                   ← L4 特性·自身（击杀叠层，上限 10 层 = +40%，跨桶乘算）
  ÷（1 + 角色技能常驻攻速% ）                    ← L4 角色技能·自身（周仓·死战等）
  ÷（1 + 科技攻速% ）                            ← L2 科技（弓手职业分支）
最终 wait_time = max(上式, attack_cooldown × 0.55)   ← L5 攻速下限（ATTACK_SPEED_FLOOR）
```

来源链：
1. `attack_cooldown`（L0/L1）：`compute_stats_at` 的 `attack_interval = 基础间隔 × 转职攻速倍率 × 信物攻速因子`；入战再乘局内遗物攻速因子（多件相乘，L3）；升阶后 `attack_cooldown = _base_attack_cooldown ÷(1 + 攻速步进 × rank)`（L4）。
2. **临时攻速桶入表源清单**（均 `apply_attack_speed_buff`，同 source 刷新不叠加、异 source 加法、总 clamp +100%）：舞娘大招 `ult_dancer_encourage`（+30%）、虎贲破阵激励段 `ult_tiger_guard_sweep`（+15%）、舞娘光环脉冲 `aura_attack`（+20%）、连击 `combo`（5/10/15 连击 +5/10/15%）、擂鼓（军需 `supply`，+30%）、舞娘职业技能 `skill_inspire`、携民渡江 `char_carry_people`、七进七出 `char_seven_charges`。
3. **表外自身强化**（龙魂叠层、角色技能常驻、科技）保留独立乘算的语义依据：三者都是「自身」或「编队层」来源，不与「友方施放」同类；但文档要求新增同类攻速来源一律入表，禁止再造表外乘点。

## 4. 射程与范围管线

```text
射程 =（base_range + 射程成长 ×(等级-1)）× 转职射程倍率 + 信物射程加值    ← L0/L1 compute_stats_at
  ×（1 + 诸葛亮·观星 12%）                        ← L1 特性静态（trait_star_gazer）
  ×（1 + 局内遗物射程% Σ）                        ← L3（多件相加）
  ×（1 + 升阶射程步进 × rank）                    ← L4 apply_battle_rank
攻击判定 = 目标距离 ∈ [min_range, 射程]（min_range 仅投石车 160px，L0）
```

范围（AOE 半径）单独走：`基础溅射半径 × 转职/技能范围倍率 ×（1 + 升阶 AOE 步进 × rank）×（1 + 术士奇谋大招范围%×s）`——范围类效果的上限随阶段 9 前按 10.10 补全。

## 5. 大招强度与怒气管线

### 5.1 大招强度

```text
ultimate_power =（1 + 职业伤害步进 × battle_rank）× 转职大招倍率（PromotionData.ultimate_multiplier）
大招结算值 = damage × 行为倍率（3×/1.5×/2× 等）× ultimate_power → 进入 finalize_damage 尾段乘区
```

- 大招与普攻「升阶伤害同源」（v0.21.0）：升阶对普攻与大招的放大一致，`ultimate_power` 不含临时攻速桶（大招无攻速概念）。
- 大招倍率按 SKILLS.md 4.1 分线预算（一转 ×1.2~1.33 / 二转强化 ×1.2~1.3 / 新技能线 ×1.15 均以未转职为基准），与普攻分账。
- ⚠️ 大招结算仍吃 `finalize_damage` 尾段（光环/条件增伤/易伤）——因此基准测试（提交 10）必须把普攻/大招/总 DPS 分列断言，防止「光环桶上限」被大招放大路径绕过。

### 5.2 怒气（满 100 释放，L5 上限）

```text
本次积怒 = 基础积怒 × 貂蝉月幕倍率 ×（1 + 科技怒气%）
  基础积怒：输出（hit+damage）= 命中 +N/次 + 该次实际伤害 ×M/10 点伤害（职业参数）
            辅助（support）= 增益脉冲 +N + 每覆盖 1 名友方 +K（5s 去重、按塔实例计）
  貂蝉月幕：自身 ×1.2、友方在场 ×1.1（BehaviorRegistry.moon_veil_rage_multiplier）
释放：怒气满 100 → 手动/自动；释放先清怒再结算，大招击杀返怒（骑兵基础 50%、蓄力+ 70%×s）在清零后叠加
```

- 命中口径（v0.31.4 / 0.8.6.2）：远程弹道实际命中造成伤害后才积怒；目标飞行中死亡/丢失/空爆不积怒；AOE 每发一次按该发伤害计、不按命中数叠加；大招/主动技能弹道不接普攻命中事件。

## 9. 收敛三档落地（v0.31.6 拍板，排期定稿）

### 档次 1（阶段 8·提交 7，✅ v0.32.0 / 0.8.7.0 落地）——常驻光环伤害桶（军旗 + 仁德）

- **目标（✅ 已达成）**：刘备仁德（+8%）与虎贲军旗（`command`，数值以 SKILLS 2.2 为准：一转 +4%×s、半径 150；陷阵军旗+ +6%×s、半径 180）同属「友方伤害光环」，从各自独立乘算收敛为**加法求和 + 桶上限（+50% 初稿）**；军旗从 `SkillRegistry.passive_damage_multiplier()` 移出，仁德从 `finalize_damage` 独立乘点移出。
- **实现落点（✅ v0.32.0）**：`Tower.refresh_aura_damage_bonus()` 扫描全塔组汇总仁德/军旗（`_aura_damage_bonus`，clamp 0~`AURA_DAMAGE_CAP`=0.5）；建塔/拆塔/离场（`_exit_tree` 广播）事件驱动刷新 + 0.25s 低频兜底扫描 + `finalize_damage` 前惰性节流；`finalize_damage` 只乘一次 `(1 + _aura_damage_bonus)`；多虎贲互乘与「军旗 × 仁德」互乘消除。
- **连带**：`passive_damage_multiplier` 保留破城/定军山（属目标条件增伤，档次 3 预算）；易伤（奇门）实现时进目标侧乘区（非塔侧光环桶）。
- **验收（✅ v0.32.0 SmokeRunner 专项断言）**：单军旗（一转 4%）+ 仁德 = 桶 0.08+0.04=0.12、5 阶军旗 0.124；军旗+（6%×s）5 座 = 0.42 加法求和、6 座 0.504 → clamp 0.5；`finalize_damage` 只乘一次（探针 100×1.42=142 / ×1.5=150）；双虎贲不再出现乘算路径。数值口径以 SKILLS 2.2 为准：军旗+ 与仁德叠加 s=1 时 ×(1+0.06+0.08)=×1.14。

### 档次 2（阶段 8·提交 10，✅ v0.35.0 / 0.8.10.0 落地）——编队加成伤害桶

- **目标（✅ 已达成）**：`finalize_damage` 首行 `(1+科技全局)×(1+科技职业分支)×(1+羁绊)` 三连乘 → 层内加法 `(1 + 科技全局% + 科技职业分支% + 羁绊%)`，clamp 合计 ≤+30%；信物（L1）与局内遗物（L3）保持跨层乘算不变。
- **实现落点（✅ v0.35.0）**：`Tower.finalize_damage` 首行收敛为 `(1 + clampf(_tech_damage_bonus + _tech_profession_damage_bonus + _bond_damage_bonus, 0, FORMATION_DAMAGE_CAP))`，`FORMATION_DAMAGE_CAP = 0.3`（scripts/Tower.gd）；只乘一次，消除「科技全局 × 职业分支 × 羁绊」同层叠乘。
- **验收（✅ v0.35.0 BenchmarkRunner 专项断言）**：全加成归零口径下基准 1~4 数值与现状一致（全部落预算）；编队桶非零抽样 `0.15+0.10+0.05 → ×1.30`（旧三连乘 1.15×1.10×1.05=1.328 已消除）、超限 `0.20+0.10+0.10 → clamp ×1.30`、信物（×1.10）/ 局内遗物（×1.05）跨层乘算保留（×1.30×1.10×1.05）、`FORMATION_DAMAGE_CAP == 0.3` 常量断言。

### 档次 3（阶段 8·提交 10，✅ v0.35.0 / 0.8.10.0 基准校准）——条件增伤乘区预算与登记

- **目标（✅ 已登记）**：给「目标条件增伤」立预算表并登记全部现有乘点：职业克制（虎贲 cavalry +15%）、特性（武圣 精英/Boss +25%、周仓 高血 +30%、百步 3×10%、火攻 AOE +15%）、破城（精英/Boss +10%×s）、定军山标记 +15%、易伤（提交 7，奇门 +10%×s，同类不叠加只刷新）。规则：**单项 ≤+30%**（含档位系数 s 放大后仍不超），超过即触发平衡审查；新增条件增伤必须先在本文档登记才能开发。
- **验收（✅ v0.35.0 BenchmarkRunner 基准 3）**：精英/Boss DPS 窗逐项断言乘点实测值 ∈ 预算——武圣 ×1.250、百步 ×1.300、破城 ×1.100、定军山 ×1.149 全部 ≤×1.30（周仓高血/火攻探针在普通与条件桩两侧均触发、无差分，以 ×1.0 基数通过）；击杀返怒循环（蓄力基础 50%）实测 60s 18 大招 / 352.75 DPS；基准报告输出「条件乘区实际组合值」供平衡讨论。
